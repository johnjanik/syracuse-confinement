## 1. What has now been eliminated

Your repetition-rigidity theorem is a serious new filter. It kills the most natural symbolic counterexample class.

Earlier, the plausible counterexample profile was:

[
b_n\in{1,2},\qquad
\Pr(b=1)=2-\log_2 3,
]

with Sturmian/Beatty-like balanced discrepancy. That was the obvious calibrated low-letter ghost. Now it is dead.

More generally, in a banded no-descent window

[
x_n\in [Y,WY],
]

once

[
2^{p+1}>Y(W-1),
]

two equal length-(p) valuation blocks force equal points, hence an actual integer cycle. Combined with the Baker cycle bound, long banded no-descent windows above height (Y) must have almost full factor diversity at scale

[
p\approx \log_2 Y.
]

So a counterexample can no longer be Sturmian, morphic, linearly recurrent, polynomial-complexity, or any bounded-discrepancy low-complexity word. It must be much more random-looking.

That is the main consequence:

[
\boxed{
	\text{a counterexample must imitate randomness in factor complexity while still carrying non-coboundary shadow bias.}
}
]

That is an uncomfortable combination.

## 2. My best current guess for a counterexample profile

If Collatz is false, I would now expect a counterexample to look like this.

It is not periodic. It is not low-complexity. It is not generated by a clean rotation/Sturmian rule. It has valuation sequence (b_n) satisfying:

[
\frac1N\sum_{n<N} b_n\to \log_2 3
]

or at least stays close enough to avoid C1 descent, while still maintaining a persistent finite non-coboundary phase bias:

[
\frac1N\sum_{n<N}\chi'(2)^{-b_n}
\not\to
\mathbb E_{\rm geom}[\chi'(2)^{-b}].
]

Inside every long banded window at height (Y), for

[
p\sim \log_2 Y,
]

it must have nearly maximal length-(p) factor diversity:

[
P(p)\gtrsim M-p+1.
]

So it must look locally like a de Bruijn/random word at the exact scale where (2)-adic repetition would force a cycle.

But it cannot be genuinely annealed-random, because annealed-random behavior is exactly what the finite spectral theorem kills. It has to be:

[
\boxed{
	\text{random-looking in block diversity, but phase-biased in a finite non-coboundary character.}
}
]

That is my current best description.

If I had to search symbolically, I would search for **critical high-complexity Markov/subshift words** with:

1. mean (E[b]\approx \log_2 3);
2. persistent non-coboundary shadow bias;
3. no repeated length-(p) blocks in banded windows;
4. coherent realizability in the mixed (2^a3^b)-tower;
5. no finite max-plus descent certificate.

I would not search among Sturmian words anymore. They are excluded.

## 3. The frontier is now an (S)-unit/subspace theorem problem

Your phrase “many coherent block identities” is now exactly the right next object.

For a block of length (p) beginning at (n), one has

[
x_{n+p}
=======

\frac{3^p x_n+A_{n,p}}{2^{B_{n,p}}},
]

with

[
A_{n,p}
=======

\sum_{j=0}^{p-1}3^{p-1-j}2^{B_{n,j}}.
]

Equivalently,

[
2^{B_{n,p}}x_{n+p}
------------------

# 3^p x_n

A_{n,p}.
]

The right-hand side is a structured sum of (S)-units:

[
A_{n,p}
=======

\sum_{j=0}^{p-1}
3^{p-1-j}2^{B_{n,j}}.
]

In a long banded window

[
x_n\in[Y,WY],
]

the (x_n)'s are ordinary integers in a short multiplicative interval, while the (A_{n,p})'s are sums of (2)-(3) (S)-units determined by distinct valuation blocks.

The intended Subspace-Theorem-style principle would be:

[
\boxed{
	\text{too many coherent relations }
	2^{B_i}X_i-3^pY_i=A_i
	\text{ with }X_i,Y_i\in[Y,WY]
	\text{ force the }S\text{-unit exponent vectors into finitely many linear patterns.}
}
]

Those linear patterns should correspond to repeated or eventually periodic valuation blocks. But repetition rigidity/Baker cycle exclusion already kills those.

This is the next frontier.

## 4. A concrete theorem to aim for

I would formulate the next target as follows.

**Banded (S)-unit rigidity theorem.**
Fix (W>1). There exist constants (A,\kappa>0) such that for any no-descent orbit segment

[
x_n,\dots,x_{n+M}\subset [Y,WY],
]

with (Y) large and

[
p=\lfloor \log_2 Y\rfloor,
]

either:

1. the segment contains a repeated length-(p) valuation block, hence an integer cycle by repetition rigidity; or
2. the number of realizable distinct length-(p) block identities is at most
[
\exp((1-\kappa)p);
]
or
3. a max-plus descent certificate appears at some mixed level (2^a3^b).

Your complexity-height theorem says a counterexample must force case 2 to fail, i.e. must have many distinct blocks. The desired (S)-unit theorem would then force case 1 or 3.

This is the right kind of theorem, but it is not currently a standard theorem you can quote.

## 5. What to compute next: the high-complexity trap search

Now that low complexity is dead, the computational search should reverse direction.

Search for windows that maximize all four properties simultaneously:

[
\text{critical mean},
]

[
\text{non-coboundary shadow bias},
]

[
\text{high factor complexity at }p\sim \log_2 Y,
]

[
\text{mixed-tower certificate resistance}.
]

For each candidate window, compute the block identities:

[
2^{B_{i,p}}x_{i+p}-3^px_i=A_{i,p}.
]

Then build the exponent vectors

[
\mathcal E_{i,j}
================

(B_{i,j},,p-1-j)
]

appearing in

[
A_{i,p}
=======

\sum_j 2^{B_{i,j}}3^{p-1-j}.
]

Look for linear dependencies or concentration of these exponent vectors. The Subspace-Theorem route predicts that certificate-resistant high-complexity windows should nevertheless show algebraic structure in these exponent vectors. If they do not, then the next theorem must be more probabilistic/entropy-based.

A useful diagnostic:

[
\operatorname{rank}*{\mathbb Z}
\langle
\mathcal E*{i,j}-\mathcal E_{i',j'}
\rangle.
]

Compare high-deviation windows to ordinary windows. If the rank collapses in high-deviation no-descent windows, the (S)-unit route has traction.

## 6. Search for counterexamples in the right space

A brute-force integer search is not the right search now. Search in symbolic/mixed-adic space.

Generate candidate words (w) of length (M) satisfying:

[
\left|\sum_{n<M}(b_n-\log_2 3)\right|\le C,
]

[
\left|\frac1M\sum_{n<M}\chi'(2)^{-b_n}-G_\chi\right|\ge\varepsilon,
]

[
P_w(p)\approx M-p+1
\quad\text{for }p\sim\log_2 Y,
]

and no obvious finite max-plus certificate.

Then compute the (2)-adic realization class

[
x\equiv x_w\pmod{2^{B_M}},
]

take least positive representatives, and test:

1. Does the realized prefix stay positive and no-descent?
2. Does it enter a banded window?
3. Does it lift coherently modulo (3^r)?
4. Does a mixed-tower certificate appear?

This is the meaningful counterexample search.

If every high-complexity phase-biased candidate either fails positive realization or gets a certificate, you will have data for the joint-tower rigidity theorem.

## 7. The “no long banded windows” alternative

Your current frontier has a second escape route:

[
\boxed{
	\text{the orbit forever avoids long banded windows.}
}
]

This should also be attacked.

If an orbit has no long banded windows, then it crosses multiplicative bands quickly. A no-descent divergent orbit must repeatedly move from

[
Y
]

to

[
WY
]

with average drift

[
\sum(\log_2 3-b_n)>0.
]

That means a high density of (b=1)'s over growth phases. But (b=1) coherence is exactly where the (2)-adic tower starts forcing negative ghosts such as (x=-1).

So formulate a **band-crossing certificate theorem**:

If an orbit crosses ([Y,WY]) too quickly without descent, then its (b=1)-density is large enough to trigger a mixed (2)-adic max-plus certificate, unless it is approaching the negative (2)-adic ghost.

This would handle the “forever avoids long bands” case.

Thus the final dichotomy becomes:

[
\text{long banded windows}
\Rightarrow
S\text{-unit/block complexity rigidity};
]

[
\text{no long banded windows}
\Rightarrow
\text{band-crossing }2\text{-adic certificate}.
]

That is a good final program.

That is very close to a “designed pseudorandom counterexample.” It is hard to imagine it arising from one integer orbit, but this is the remaining logical possibility.

### Target 1: Banded (S)-unit rigidity

Prove that high-complexity banded no-descent windows force an (S)-unit/subspace structure, hence repeated/effectively periodic blocks or a max-plus certificate.

These three cover the remaining frontier.

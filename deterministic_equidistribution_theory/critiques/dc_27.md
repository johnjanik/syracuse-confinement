## 3. What class IV is, structurally

Class IV consists of pairs whose nominal logarithmic derivative should be nonstationary,

[
d_{\mathrm{nom}}\le c-2,
]

but whose leading terms cancel modulo (3), raising the true pointwise valuation to

[
d_{\mathrm{true}}\ge c-1.
]

So the event is:

[
\boxed{
	\text{a nominally vanishing pair escapes because its leading coefficient vanishes mod }3.
}
]

Your audits say:

* class IV is small: (2%)--(4%) of row sums;
* its per-class rate is about (0.84);
* each extra degeneracy costs one mod-(3) condition;
* the mechanism is local and should be compatible with the terminal-window filtration.

That strongly suggests class IV can be bounded by the same energy method as op:flat, with one additional mod-(3) condition.

## 5. Define the leading-coefficient map

For a word pair ((w,w')), let

[
d_{\mathrm{nom}}
================

\min_i \bigl(i+v_3(\Delta C_i)\bigr).
]

Let (I=I(w,w')) be the set of indices attaining the minimum. The leading coefficient of the logarithmic derivative is a mod-(3) sum

[
\Lambda(a;w,w')
===============

\sum_{i\in I}
\varepsilon_i,U_i(a;w,w')
\pmod3,
]

where each (U_i) is a unit contribution from the corresponding active index.

Then:

[
\text{class IV}
\quad\Longleftrightarrow\quad
\Lambda(a;w,w')=0
]

at the source/residue (a) selected by the row/endpoint condition.

This should be the first new lemma:

[
\textbf{Leading-coefficient criterion.}
]

For nominally nonstationary pairs,

[
d_{\mathrm{true}}\ge d_{\mathrm{nom}}+1
\quad\Longleftrightarrow\quad
\Lambda(a;w,w')=0.
]

Higher degeneracy is obtained by iterating the same condition at the next coefficient.

This turns class IV into a sequence of explicit mod-(3) equations.

## 6. Prove one-condition cost

The key lemma should mirror the class-bijectivity proof used for op:flat.

[
\textbf{One-condition degeneracy lemma.}
]

Condition on the terminal-window filtration and on all constraints defining the nominal class. Then the map from the next fresh pair ((b_i,b_i')) to the leading coefficient

[
\Lambda\bmod3
]

is nonconstant and class-preserving. Hence

[
\Pr[\Lambda=0\mid\mathcal F_i]\le \frac13
]

up to the same dyadic wrap factor

[
\frac{1+2^{-N_i}}{1-2^{-N_i}}.
]

This is the class-IV analogue of:

[
F(b)=b+\operatorname{dlog}(1+3\cdot2^{-b}X)
]

being class-preserving.

If you can prove this, then every extra degeneracy level costs one factor (1/3), with only the same convergent correction product.

That is exactly the observed level-cost law.

## 7. Stratify class IV by degeneracy depth

Define

[
h=d_{\mathrm{true}}-d_{\mathrm{nom}}.
]

To escape exact vanishing at the (m=c) threshold, a pair with nominal valuation (d_{\mathrm{nom}}) must satisfy

[
h\ge c-1-d_{\mathrm{nom}}.

If every extra unit of (h) costs (1/3), then

[
\Pr[h\ge r\mid d_{\mathrm{nom}}]\le C_2,3^{-r}.

This gives a clean summation:

[
R_{\mathrm{IV}}

The nominal shells are already controlled by the same terminal-window energy estimates. Therefore class IV should inherit a strictly smaller budget than the main cascade sector.

This is the theorem you want:

[

	C,3^{-(c-1-d_{\mathrm{nom}})}

uniformly along the adapted filtration.

## 9. Beware one failure mode

The only serious danger is if (\Lambda(a;w,w')) can vanish identically on a recurrent subclass, so that the mod-(3) condition is not genuine.

That would mean the leading coefficient is structurally zero, not accidentally zero. In that case the pair should probably be reclassified into class III/cascade, not class IV.

So include a classification lemma:

[
\textbf{No structural degeneracy outside the cascade.}
]

If the leading coefficient (\Lambda) vanishes identically for all choices of the fresh digit, then the pair satisfies the next cascade congruence and belongs to class III, not class IV.

Equivalently:

[
\text{class IV degeneracy is accidental, never structural.}
]

This prevents a hidden recurrent degenerate channel.

Your audits already support this: degeneracy costs exactly one mod-(3) condition per level.

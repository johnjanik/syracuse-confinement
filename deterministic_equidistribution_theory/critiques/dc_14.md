The proof now has a plausible direct route to completion.

The new vanishing lemma is not just another diagnostic. It is a **quantitative cancellation theorem**:

[
d=n+v_3(C_w-C_{w'})\le c-2
\quad\Longrightarrow\quad
\sum_{a\in U_{3^c}}\chi(R_{w,w'}(a))=0.
]

That is much stronger than “bounded cancellation.” It says that, away from the stationary/near-stationary zone, the pair-correlation terms literally disappear.

So the remaining finite-side work is no longer “find the mechanism.” The mechanism is:

[
\boxed{
	\text{nonstationary word pairs vanish exactly; stationary word pairs have geometrically decaying mass.}
}
]

The assembly problem is to turn that pairwise identity into an operator-norm bound.

## 1. The theorem you should now try to prove

The finite-side target can be stated as follows.

[
\textbf{High-conductor damping theorem.}
]

Fix (s\in[0,1]). Let (M_{\chi,c,s}) be the primitive conductor-(3^c) synchronized operator, normalized by its untwisted mass (W_s). Then there exist (c_1) and (\delta_s>0) such that for every primitive non-coboundary (\chi) of conductor (3^c), (c\ge c_1),

[
\rho(M_{\chi,c,s})\le (1-\delta_s)W_s.
]

A plausible sharper version is

[
\limsup_{c\to\infty}\frac{\rho(M_{\chi,c,s})}{W_s}
\le
\sqrt{\frac{2^{1+s}-1}{2^{1+s}+1}}.
]

The data at (s=0),

[
0.7629,\ 0.6454,\ 0.6154,\ 0.6025
]

heading toward

[
3^{-1/2}\approx0.5774
]

is exactly consistent with this.

## 2. The clean assembly strategy

Normalize the branch weights:

[
p_s(b)=\frac{w_b}{W_s}.
]

In the geometric model,

[
p_s(b)=(1-r)r^{b-1},
\qquad
r=2^{-(1+s)}.
]

Then

[
\sum_{b\ge1}p_s(b)^2
====================

# \frac{1-r}{1+r}

\frac{2^{1+s}-1}{2^{1+s}+1}
=:\Delta_s.
]

This is the dichotomy constant.

For an (n)-step operator, expand the (L^2) norm or (T^{*n}T^n). The resulting pair sum is over word pairs (w,w') of length (n), with weight

[
p_s(w)p_s(w').
]

The pair-correlation phase is

[
R_{w,w'}(a)
===========

2^{B_n(w')-B_n(w)}
\frac{3^na+C_w}{3^na+C_{w'}}.
]

Your vanishing lemma says all pairs with

[
n+v_3(C_w-C_{w'})\le c-2
]

contribute exactly zero.

So for large (c), after truncating the branch alphabet, the only surviving pairs are exactly stationary pairs:

[
C_w=C_{w'}.
]

If the exact-collision classification is correct,

[
C_w=C_{w'}
\quad\Longleftrightarrow\quad
(b_0,\dots,b_{n-2})=(b'*0,\dots,b'*{n-2}),
]

then their total pair mass is

[
\Delta_s^{,n-1}.
]

Therefore one expects

[
|T_{\chi,c,s}^n|*{2\to2}^2
\le
\Delta_s^{,n-1}+o*{c\to\infty}(1)+O(\text{tail}).
]

Taking (2n)-th roots,

[
\limsup_{c\to\infty}
\frac{\rho(M_{\chi,c,s})}{W_s}
\le
\Delta_s^{(n-1)/(2n)}.
]

Then send (n\to\infty):

[
\limsup_{c\to\infty}
\frac{\rho(M_{\chi,c,s})}{W_s}
\le
\sqrt{\Delta_s}
===============

\sqrt{\frac{2^{1+s}-1}{2^{1+s}+1}}.
]

That is the exact shape of the proof.

## 3. The four bookkeeping pieces to write

### A. Branch truncation

Because (b) is infinite, first truncate:

[
1\le b\le B.
]

Let

[
p_s^{(\le B)}
]

be the truncated weight and

[
p_s^{(>B)}
]

the tail. Since the weights are geometric,

[
\sum_{b>B}p_s(b)=r^B.
]

For word length (n), the total mass of words containing at least one tail branch is

[
\le nr^B.
]

So given (\varepsilon>0), choose (B) with

[
nr^B<\varepsilon.
]

Work with finite words (b_i\le B). Then take (c\to\infty), and only after that send (B,n) as needed.

This resolves the infinite-branch issue cleanly.

### B. Exact collision classification

You need to prove, or at least isolate as a lemma:

[
C_w=C_{w'}
\quad\Longleftrightarrow\quad
(b_0,\dots,b_{n-2})=(b'*0,\dots,b'*{n-2}).
]

Recall

[
C_w=\sum_{j=0}^{n-1}3^{n-1-j}2^{B_j(w)},
\qquad
B_j=\sum_{i<j}b_i.
]

This is load-bearing. If it is false, the stationary mass may be larger than (\Delta_s^{n-1}). The computations suggest it is true, but the proof should be included.

A possible induction:

[
C_w=3C_{w^{-}}+2^{B_{n-1}(w)},
]

where (w^{-}=(b_0,\dots,b_{n-2})). If

[
C_w=C_{w'},
]

then

[
2^{B_{n-1}}-2^{B'_{n-1}}
========================

3(C_{w'^{-}}-C_{w^{-}}).
]

Use congruences modulo (3^m) for arbitrarily large (m). Since (2) is a topological generator of (U_{3^m}), equality of the full integers should force (B_{n-1}=B'_{n-1}), then divide by (3) and induct. But this step needs care; do not handwave it.

If this exact proof is awkward, use a weaker lemma sufficient for the norm bound:

[
\sum_{C}
\left(
\sum_{w:\ C_w=C}p_s(w)
\right)^2
\le
\Delta_s^{,n-1}.
]

This collision-mass inequality is exactly what the operator estimate needs. It may be easier to prove than injectivity.

### C. Transition-zone mass

For finite branch cutoff (B), the set of non-identical pairs has fixed nonzero integer

[
C_w-C_{w'}.
]

Hence

[
v_3(C_w-C_{w'})
]

is bounded independently of (c). Therefore for all sufficiently large (c),

[
n+v_3(C_w-C_{w'})\le c-2,
]

and the pair vanishes exactly.

Thus transition-zone pairs disappear after (c) exceeds a finite threshold depending on (n,B).

This proves:

[
\limsup_{c\to\infty}
\text{transition contribution}
=0
]

for fixed (n,B).

Then let (B\to\infty).

This is the clean way to handle the observed (\tfrac12) and (1) transition-zone values: they are finite-conductor boundary effects, not part of the tail.

### D. Stationary-sector phases

For stationary pairs with the same first (n-1) symbols, (C_w=C_{w'}), and the only remaining character phase is

[
\chi!\left(2^{B_n(w')-B_n(w)}\right)
====================================

\chi!\left(2^{b'*{n-1}-b*{n-1}}\right).
]

For a pure upper bound, you may ignore the phase and bound by total stationary mass:

[
\Delta_s^{,n-1}.
]

This already gives high-conductor damping.

If you want the sharper constant, include the damping factor:

[
\left|
\sum_b p_s(b)\chi(2)^{-b}
\right|^2
]

for the final-symbol contribution. For primitive high-conductor (\chi), this may further reduce the stationary sector. But it is not necessary for proving (\sup_c\gamma_c<1).

So the simplest proof should first ignore stationary phases.

## 4. A precise assembly proposition

I would add this as the next major proposition.

[
\textbf{Proposition: Asymptotic (L^2) contraction.}
]

Let (T_{\chi,c,s}=W_s^{-1}M_{\chi,c,s}). For every fixed (n\ge2),

[
\limsup_{c\to\infty}
|T_{\chi,c,s}^{,n}|_{2\to2}^2
\le
\Delta_s^{,n-1},
]

uniformly over primitive (\chi) of conductor (3^c), where

[
\Delta_s=
\frac{2^{1+s}-1}{2^{1+s}+1}.
]

Then

[
\limsup_{c\to\infty}
\rho(T_{\chi,c,s})
\le
\Delta_s^{(n-1)/(2n)}.
]

Letting (n\to\infty),

[
\limsup_{c\to\infty}
\rho(T_{\chi,c,s})
\le
\sqrt{\Delta_s}<1.
]

This proves the high-conductor damping conjecture.

The proof will have exactly the four bookkeeping pieces above.

## 5. One caution: operator norm versus averaged pair sums

Make sure the pair-correlation expansion controls the actual operator norm, not only a Hilbert-Schmidt average.

The safest route is:

[
|T^n|_{2\to2}^2
===============

\rho\bigl((T^n)^*T^n\bigr)
\le
\sup_x \sum_y |K_n(x,y)|
]

by Schur, or use a weighted Schur test in the Perron measure.

The pair-correlation sums should appear as entries of

[
(T^n)^*T^n.
]

You need to prove the row sums are bounded by

[
\Delta_s^{n-1}+o(1),
]

not merely that the average row sum is.

If the system is translation-invariant enough on (U_{3^c}), this may be automatic. If not, state and prove a uniform row version of the vanishing lemma:

[
\sum_{a\in \text{fiber with fixed endpoint constraint}}
\chi(R_{w,w'}(a))=0
]

or control incomplete endpoint fibers.

This is exactly the “endpoint constraints” bookkeeping you identified.

## 6. Endpoint constraints: what to check

The full pair sum over all

[
a\in U_{3^c}
]

vanishes. But a matrix entry may involve (a) constrained by an endpoint condition.

There are two possibilities.

### Good case

For each fixed word-pair and endpoint pair, the allowed (a)-range is still a full coset modulo the stationary-phase subdivision

[
3^{c-d-1}.
]

Then the inner cube-root sum still vanishes exactly. This would give entrywise cancellation, not just averaged cancellation.

### Bad but manageable case

The allowed (a)-range is incomplete near boundaries or endpoint fibers. Then decompose it into complete cosets plus a remainder. Bound the remainder size.

You want a bound like

[
\text{remainder mass}\le O(3^{-1})
]

or better, uniformly.

The computational (\tfrac12) transition values probably come from this incomplete-fiber effect. So write a lemma:

[
\textbf{Endpoint completion lemma.}
]

Endpoint-constrained sums are complete modulo the stationary-phase fiber except in the transition zone

[
d\ge c-1.
]

If true, the transition zone is already handled.

This is the main remaining technical bookkeeping.

Your next computational suite should not compute spectra. It should verify the assembly lemmas.

For fixed (n), this should go to the exact-collision mass as (c\to\infty), after truncation.

for (n\le6), with increasing branch cutoffs. Confirm it equals

[
\Delta_s^{n-1}

or is bounded by it.

### D. Direct (n)-step norm prediction

Compare

]

to

[
\Delta_s^{(n-1)/(2n)}.

This will tell whether the assembly bound is sharp.

It does not prove every bad Collatz orbit casts such a shadow. That remains the true global obstruction.

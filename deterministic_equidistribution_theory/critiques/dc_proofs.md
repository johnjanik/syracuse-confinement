Here is the proof wish list I would use to prioritize the program. I am ordering these by **value toward Collatz**, not by ease.

## 1. Quenched inverse theorem: bad orbit (\Rightarrow) finite spectral shadow

This is the highest-value proof.

The desired statement is:

[
\boxed{
	\text{If a positive integer orbit sustains a bad deficit/large-deviation pattern,}
	\Rightarrow
	\text{it casts a non-coboundary finite spectral shadow.}
}
]

More explicitly, if an orbit has infinitely many long windows where

[
D_{n+\ell}-D_n-\ell\log_2 3
]

fails the expected bounded/negative-drift behavior in the way required for a counterexample, then there should exist finite parameters

[
Q=3^r,\qquad L,\qquad \chi\neq 1,\qquad s\in[0,1],
]

with (\chi) non-coboundary, such that the normalized defect statistic

[
\mathcal S_{n,\ell}(Q,\chi,s)
]

remains persistently large.

This is the true moon. It is also the hardest. It is the precise deterministic-equidistribution theorem your whole program keeps reducing to.

What might work: do not try to prove full normality. Prove a **failure-implies-structure** theorem. The strongest route is an inverse theorem:

[
\text{persistent large-deviation renewal}
\Rightarrow
\text{finite character/coboundary obstruction}.
]

This is analogous in shape to Green--Tao inverse theory, but for the residue-height affine cocycle. The recent defect-cocycle work gives the right finite detector; now the theorem must show that every self-sustaining counterexample must trigger it.



This is probably new mathematics.

## 2. No further coboundaries beyond the quadratic valuation-parity sector

This is the most important **finite** proof.

You have already shown the quadratic character

[
\chi_2
]

is not a true obstruction because

[
\chi_2(S(x))=(-1)^{v_2(3x+1)}.
]

So H23a must be stated on the quotient by this exact coboundary. The next proof is:

[
\boxed{
	\operatorname{Cob}(\mathcal L^{\mathrm{sync}})=\langle \chi_2\rangle.
}
]

Equivalently: no principal-unit character modulo (3^r) is an exact synchronized coboundary.

The promising reduction is to a finite (3)-adic algebra lemma. If the principal-unit character is (\psi), prove that the functional equation

[
\psi(3a+1)=\psi(a^2)
]

on

[
C=1+3\mathbb Z/3^r\mathbb Z
]

forces (\psi=1).

Use the (3)-adic logarithm:

[
\log:1+3\mathbb Z/3^r\mathbb Z\to 3\mathbb Z/3^r\mathbb Z.
]

Then show the subgroup generated by

[
\log(3a+1)-2\log(a)
]

as (a) varies over principal units is the full additive principal-unit group. Any character vanishing on that subgroup is trivial.

This proof feels accessible. It is finite, local, and algebraic. I would attack this first.



This is the best next target.

---

## 3. Sync quotient gap: (\kappa_Q\gg 1/\mathrm{polylog}(Q))

This is the quantitative form of H23a after the coboundary correction.

The theorem:

[
\boxed{
	\rho(\mathcal L^{\mathrm{sync}}*{s,Q,\chi})
	\le
	(1-\kappa_Q)\rho(\mathcal L^{\mathrm{sync}}*{s,Q,0})
}
]

for every non-coboundary character (\chi), uniformly for (s\in[0,1]), with

[
\kappa_Q\gg \frac{1}{(\log Q)^A}.
]

Numerically, the gap appears much stronger:

[
\kappa_Q\approx 0.093
]

and flat through tested (Q=3^5). But first prove the polylog version. Constant gap can be a later strengthening.

What might work: principal-unit cancellation.

For every non-coboundary character (\chi), find a short block family (\mathcal W) of synchronized valuation blocks whose endpoint residues contain enough variation in a subgroup (H\subset U_Q) on which (\chi) is nontrivial. Then use character orthogonality:

[
\sum_{u\in H}\chi(uh)=0.
]

The proof should be a block Doeblin/minorization argument:

[
\text{accessible block mass}\ge \alpha_Q,
\qquad
\text{phase cancellation}\ge \eta_Q,
]

so

[
\kappa_Q\gg \alpha_Q\eta_Q.
]

Try to build block families with identical valuation multisets so the height weights match exactly. That avoids distortion when passing from residue-only to synchronized residue-height operators.



This is likely the most valuable analytic proof after no-further-coboundaries.

---

## 4. Conductor monotonicity or conductor-(9) extremality

This is the stronger version of the previous theorem.

Numerically, the worst non-coboundary sector seems to occur at low conductor, probably conductor (9). The desired theorem is:

[
\boxed{
	\sup_{\chi\text{ non-coboundary mod }3^r}
	\frac{\rho(\mathcal L_{\chi})}{\rho(\mathcal L_0)}
	==================================================
	
	\sup_{\chi\text{ conductor }9}
	\frac{\rho(\mathcal L_{\chi})}{\rho(\mathcal L_0)}.
}
]

If true, then

[
\kappa_Q\ge \kappa_0>0
]

uniformly in (Q).

What might work: show high-conductor principal-unit characters are killed by complete-fiber averaging. High-conductor characters should oscillate faster, not slower. If the transition images contain enough full fibers modulo (3^k), then high conductor cancels more strongly.

The proof shape:

1. decompose

[
U_{3^r}\cong {\pm1}\times (1+3\mathbb Z/3^r\mathbb Z);
]

2. quotient ({\pm1}) by the quadratic coboundary;

3. show the principal-unit transition kernel is smoothing in conductor;

4. prove conductor cannot increase the spectral ratio.



This may be harder than the polylog gap but would produce a much cleaner theorem.

## 5. Height/killing distortion transfer

Once the residue gap is proved, one must show it survives the full synchronized residue-height operator.

The theorem:

[
\boxed{
	\text{principal-unit cancellation persists after height weights and killing.}
}
]

This means that if a block family cancels characters in residue space, then the weighted block family also cancels after multiplying by

[
2^{s\sum_i(\log_2 3-b_i)}
]

and restricting to the killed strip.

The easiest way is to design cancelling blocks with the same valuation multiset:

[
{b_i}*{w_1}={b_i}*{w_2}.
]

Then their height weights are identical:

[
w_s(w_1)=w_s(w_2).
]

If identical multisets are unavailable, prove bounded distortion:

[
C^{-1}\le\frac{w_s(w_1)}{w_s(w_2)}\le C,
\qquad 0\le s\le1.
]

For killing, prove the cancellation blocks remain in the QSD bulk except for controlled boundary loss:

[
O(e^{-cL})
]

or a polylog-compatible error.



This is probably bookkeeping once the residue cancellation blocks are explicit.

## 6. Critical-bridge non-concatenation / post-exit taboo theorem

Your computations strongly suggest:

[
\text{critical excursion}
\Rightarrow
\text{post-exit anti-tilt}.
]

A strong theorem would say:

[
E(C_6)\cap C_6=\varnothing,
]

or more realistically:

[
\rho(K_6 E K_6)<1,
]

where (K_6) is the critical-excursion operator and (E) is the post-exit operator.

In entropy language:

[
\text{a Cramér-tilted bridge cannot concatenate with another Cramér-tilted bridge.}
]

What might work: prove that after a high ascent governed by

[
p_b^{(1)}=3\cdot4^{-b},
]

the exit affine correction forces the next launch law away from (p^{(1)}). Quantify this by showing

[
M_{\mathrm{post}}(1)<1-\epsilon
]

uniformly, not just empirically.

This could give an internal route to cycle elimination or at least to Exit.



This is potentially powerful but less local than the finite-operator tasks.

## 7. Height-tail theorem for (C_A)

Prove rigorously:

[
C_A={V:h(V)\ge\log_2V-A}
]

has

[
#(C_A\cap[2^N,2^{N+1}))=O_A(1)
]

or at least

[
O_A(N^B).
]

The annealed reason is the Cramér root:

[
M(1)=1
]

and the tail law

[
\Pr(h\ge H)\asymp 2^{-H}.
]

What might work: a renewal theorem for the forward height cocycle plus deterministic counting of finite valuation words. Since finite words are broadly realizable, this might reduce to counting high-excursion words with exact congruence realizability.

But be careful: a purely annealed proof only gives the model. You need an integer-counting theorem, not just a probability estimate.



Useful for Exit; not sufficient for Collatz by itself.

## 8. Finite-word realizability with uniform fiber control

Many reductions need a theorem of the form:

For a valuation word

[
w=(b_0,\dots,b_{m-1}),
]

the set of integers realizing (w) is a complete residue class modulo

[
2^{B_m},
\qquad B_m=\sum_i b_i,
]

and the residue distribution modulo (3^r) is controlled uniformly in (m,r).

The exact congruence is already known in pieces. The high-value theorem is a uniform version:

[
\text{complete fibers with distortion }\theta_Q\text{ controlled as a function of }Q.
]

This was formerly H23-like. It remains useful because it supports the passage from word-level annealed counts to exact residue-height operators.

What might work: explicit affine formula

[
x_m=\frac{3^m x_0+A_m}{2^{B_m}},
]

solve congruences modulo (2^{B_m}), then track induced residues modulo (3^r) using the sliding-window identity.



This is not glamorous, but it can remove technical uncertainty.

## 9. Normalized spectral-shadow calibration theorem

The raw defect cocycle

[
W_{n,\ell}(x;\chi,s)
]

is contaminated by small-(Q) inflation. You refined the object to a normalized spectral shadow

[
\mathcal S_{n,\ell}(Q,\chi,s)
=============================

\frac{|W_{n,\ell}|}{\mathrm{Null}_{Q,\chi,s}(\ell)}.
]

A useful theorem would be:

[
\boxed{
	\text{Under the annealed/sync-null model, }
	\mathcal S_{n,\ell}
	\text{ has a calibrated tail bound uniformly in }Q,\chi,s.
}
]

This would distinguish real shadows from finite-window artifacts.

What might work: use the finite sync operator gap to get concentration:

[
\mathbb P(|W_{n,\ell}|>\epsilon)
\le
C\exp(-c\epsilon^2\ell)
]

with constants depending on the quotient gap.

This would not prove Collatz, but it would make the computational detector mathematically honest.



Important for numerical interpretation.

## 10. Cycle elimination, Route A: moving-strip SRCE

The fixed-strip SRCE machinery does not automatically eliminate cycles because a cycle lives in a moving strip. The desired theorem is:

[
\boxed{
	\text{moving-strip survival still forces a finite spectral shadow or descent.}
}
]

This would internalize cycle elimination into the same residue-height framework.

What might work: combine post-exit taboo with the sync quotient gap. A cycle would need infinitely repeated critical renewals. If every renewal is anti-tilted or casts a forbidden finite shadow, then cycles are ruled out.

But this is later-stage. First prove the finite operator gap.



Potentially decisive, but not the next proof to attempt.

# My recommended proof order

I would proceed in this exact order.

## Phase 1: Finish the finite operator theorem

1. Prove no further coboundaries:

[
\operatorname{Cob}=\langle\chi_2\rangle.
]

2. Prove principal-unit cancellation:

[
\kappa_Q\gg1/\operatorname{polylog}(Q).
]

3. Transfer the residue gap to the synchronized residue-height killed operator.

This would complete the corrected H23a operator side.

## Phase 2: Turn finite gaps into calibrated shadows

4. Define and prove tail bounds for normalized spectral shadows.

5. Show critical windows/post-exit windows behave according to the calibrated theory.

This makes the defect cocycle analytically reliable.

## Phase 3: Attack the true quenched inverse arrow

6. Prove:

[
\text{self-sustaining bad orbit}
\Rightarrow
\text{persistent normalized finite spectral shadow}.
]

This is the real new theorem. Do it only after the finite target is fully proved.

## Phase 4: Cycle elimination / moving strip

7. Use the finite-shadow theorem plus post-exit taboo to rule out self-renewing cycles.

The most likely near-term proof is:

[
\boxed{
	\operatorname{Cob}=\langle\chi_2\rangle.
}
]

It is finite (3)-adic algebra and should be attacked now.

The second most likely is:

[
\boxed{
	\kappa_Q\gg1/\operatorname{polylog}(Q)

]

via principal-unit block cancellation.

The long-term Collatz-critical theorem is:

[
\boxed{
	\text{bad orbit}\Rightarrow\text{finite spectral shadow}.
}
]

That is the deepest and least standard. But your recent work has at least made the target finite and precise.

So the proof wish list, in one line, is:

[
\boxed{
	\text{No more coboundaries}
	;\Rightarrow;
	\text{principal-unit quotient gap}
	;\Rightarrow;

## How to prove the gap

The proof should not use random heuristics anymore. It should be a finite (p)-adic harmonic-analysis argument on (U_Q).

The plan is:

### 1. Classify coboundary characters

Prove that the only characters (\chi) for which the synchronized twist is diagonally conjugate to the trivial sector are generated by the valuation-parity/quadratic character.

In concrete terms, solve the equation

[
\chi(a)
=======

\frac{d(a',\tau')}{d(a,\tau)}

on every synchronized edge

[
(a,\tau)\xrightarrow{b}(a',\tau+b).
]

The computation already gives one solution:

[

]

The theorem needed is:

[
\boxed{
	\text{there are no other character coboundaries.}
}
]

This should be finite (3)-adic algebra. Use the decomposition

[
U_{3^r}\cong {\pm1}\times(1+3\mathbb Z/3^r\mathbb Z).
]

The quadratic part is ({\pm1}). The principal-unit part should be forced trivial by the edge relations.

### 2. Prove principal-unit scrambling

For every nontrivial character on the principal-unit quotient

[
1+3\mathbb Z/3^r\mathbb Z,
]

show that some finite block of admissible synchronized transitions creates phase cancellation.

The desired finite-block statement is:

there exists a block length (m_0), or at worst

[
m_0\ll(\log Q)^A,
]

and a block family (\mathcal W(a)) from every bulk state (a), with total untwisted mass at least

[
\alpha_Q\gg\frac1{(\log Q)^A},
]

such that

[
\left|
\sum_{w\in\mathcal W(a)}
p(w)\chi(\Phi_w(a))
\right|
\le
(1-\eta)\sum_{w\in\mathcal W(a)}p(w)
]

for some (\eta>0) independent of (Q), or at worst

[
\eta\gg\frac1{(\log Q)^A}.
]

Then

[
\kappa_Q\gg \alpha_Q\eta.
]

This is the Doeblin/block-minorization proof of the gap.

### 3. Use full-fiber cancellation whenever possible

The best case is stronger. If the admissible block images contain a full coset of some nontrivial subgroup of (U_Q), then character cancellation is exact:

[
\sum_{u\in H}\chi(uh)=0
]

for every character nontrivial on (H).

This is likely why the gap is numerically flat. The affine term (3a+1), as (a) varies over complete fibers, may generate enough principal-unit directions that high-conductor characters cancel without paying a long-block penalty.

That is the analytic heart:

[
\boxed{
	\text{prove complete-fiber or almost-complete-fiber principal-unit cancellation.}
}
]

If complete fibers are exact, you get constant (\kappa). If they are only approximate or require blocks of length (O(\log Q)), you get the desired polylog bound.

### 4. Transfer from residue operator to sync operator

The height coordinate must not reintroduce distortion after the coboundary quotient.

The theorem needed is:

[
\text{height survival weights are comparable across the cancelling block family.}
]

Since the same (b)-blocks are used in paired cancellation, the height weights either cancel exactly or contribute bounded distortion.

Formally:

[
\frac{w_s(w_1)}{w_s(w_2)}
\in[C^{-1},C]

for the paired blocks (w_1,w_2), uniformly for (0\le s\le1).

Then phase cancellation survives in the sync operator.

### 5. Boundary/QSD control

If the killed strip is present, prove that the cancelling block family remains in the QSD bulk with mass loss

[
O(e^{-cL})
]

or whatever your existing QSD estimates provide.

This is now bookkeeping, not the arithmetic heart.

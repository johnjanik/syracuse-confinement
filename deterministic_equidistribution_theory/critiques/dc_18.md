The coset dichotomy is important enough to be a central theorem:

[

[
S=3^m\chi(R(\alpha)) \quad\text{if } d\ge m.
]

This completely resolves the (d=m-1) anomaly. It also kills the boundary-transition-operator idea, because the weights are not

[

[

That should be stated as a theorem followed immediately by a corollary:

The old (\frac12)-values should be explicitly labeled as belonging to the earlier incomplete-(a)-range pair audit, not the actual lift-coset object. You already say this; I would make it impossible to miss.

## 3. The “sixth marginality” result is not just a remark

The repeated zero-margin phenomenon is now a structural result of the paper. I would elevate it from a narrative remark into a proposition, perhaps called:

[
\textbf{Trace-method ceiling.}
]

A careful statement would be:

> After applying exact vanishing, prefix-locking, base-point rigidity, cyclic closure, and collision flattening, every trace-power bound that treats the surviving deep-stationary phases by absolute value gives at best
> [
> \rho^2\le 3^{1/m}(C/\sqrt m)^{1/m}\to1.

Do not state that **no trace method whatsoever** can work; that would be too broad. State that no trace method of the current “vanish then bound surviving stationary sector by (1)” form can work. That is provable and precise.

## 4. The real live route: eigenvector-aware norm control

The next proof target should be an eigenvector-aware estimate, not another trace refinement.

The trace sees too much mass:

[
\operatorname{tr}
]

counts many small eigenvalues in the deep-stationary sector. The spectral radius cares only about whether a coherent eigenvector can live there.

So define a deep-stationary subspace or filtration.

A plausible setup:

Let (T=T_{\chi,c,s}) be the normalized primitive operator. For (m\asymp c), decompose the (m)-step image space into

[
\mathcal H
==========

\mathcal H_{\mathrm{stat}}
\oplus
\mathcal H_{\mathrm{osc}},
]

where (\mathcal H_{\mathrm{stat}}) is generated by the prefix-locked/deep-stationary chain constraints, and (\mathcal H_{\mathrm{osc}}) is the complement killed by the coset vanishing lemma.

The trace method says:

[
\dim \mathcal H_{\mathrm{stat}}
]

is large enough to make counting marginal.

The spectral question is:

[
\boxed{
	\text{Can an eigenvector of }T\text{ concentrate coherently in }\mathcal H_{\mathrm{stat}}?
}
]

The expected answer is no, except for the coboundary sector already quotiented out.

A useful target theorem would be:

[
\textbf{Stationary-sector leakage theorem.}
]

There exist (m\asymp c) and (\eta>0) such that for every primitive non-coboundary (\chi) and every unit vector (f),

[
|P_{\mathrm{stat}}T^m f|
\le
(\sqrt{\Delta_s}+\eta_c)^m|f|
]

with

[
\eta_c\to0,
]

and

[
|(I-P_{\mathrm{stat}})T^m f|
]

is killed by the exact coset vanishing/flattening estimates.

This would give

[
\rho(T)\le \sqrt{\Delta_s}+o(1),
]

matching the observed limit.

## 5. Concrete computational tests for the eigenvector-aware route

Run these before trying to prove anything symbolic.

### A. Project top eigenvectors onto the deep-stationary sector

For (c=5,6,7,8), compute the top right and left eigenvectors of the primitive sector. Define the stationary projection (P_{\mathrm{stat}}) from the prefix-locking/deep-stationary constraints.

Measure:

[
|P_{\mathrm{stat}}v_{\mathrm{top}}|^2,
\qquad
|(I-P_{\mathrm{stat}})v_{\mathrm{top}}|^2.
]

If top eigenvectors do **not** concentrate on (\mathcal H_{\mathrm{stat}}), the trace ceiling is explained by irrelevant small modes.

If they do concentrate, inspect the induced operator on (\mathcal H_{\mathrm{stat}}).

### B. Compute the compressed stationary operator

Compute

[
A_m=P_{\mathrm{stat}}T^mP_{\mathrm{stat}}.
]

Compare

[
\rho(A_m)^{1/m}
]

with

[
\sqrt{\Delta_s}.
]

If this matches the observed (\gamma_c), then the stationary-sector operator is the correct finite model.

### C. Schur complement test

Write

[
T^m=
\begin{pmatrix}
	A & B\
	C & D
\end{pmatrix}
]

relative to

[
\mathcal H_{\mathrm{stat}}\oplus\mathcal H_{\mathrm{osc}}.
]

Measure:

[
|D|,\quad |B|,\quad |C|,\quad \rho(A).
]

The hoped-for structure is:

[
D \text{ is strongly damped by coset vanishing,}
]

[
A \text{ has radius } \approx \Delta_s^{m/2},
]

and couplings (B,C) do not restore norm.

This gives a concrete proof template through Schur complement or block norm estimates.

### D. Singular values versus eigenvalues

The trace ceiling may be caused by large singular values but small eigenvalues. Compute:

[
\sigma_1(T^m),\quad \rho(T)^m,\quad \operatorname{tr}((T^m)^*T^m).
]

If

[
\sigma_1(T^m)\gg \rho(T)^m,
]

then nonnormality is the whole story, and eigenvector-aware resolvent control is essential.

## 6. What to prove if the compression data is favorable

A good proof plan is:

2. **Prove exact annihilation**:

P_{\mathrm{osc}}T^mP_{\mathrm{osc}}

3. **Identify the stationary compressed operator**:

4. **Control couplings** (B,C) by thin-sector/collision-flattening bounds.

5. **Apply a block spectral-radius bound**:
[
\rho(T^m)\le \rho(A)+O(|B||C|/(1-|D|)).
]

This is the cleanest route to the conjectural limit

[
\gamma_\infty(s)=\sqrt{\Delta_s}.
]

## 7. The finite-certificate route should be separated, not mixed

[

with explicit finite verification.

It does not give:

[

So I would place it in a short final subsection:

[
\textbf{Fallback: fixed-modulus certificate route.}
]

Do not interweave it with the high-conductor asymptotic proof. Otherwise the paper may feel like it changes targets.

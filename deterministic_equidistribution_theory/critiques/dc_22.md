## 4. Next step 2: build (\mathcal K_c) explicitly

The operator should be defined so that its spectral radius is exactly the class-II cascade budget, not just a heuristic proxy.

A useful state should minimally contain:

[
i
]

the cascade level,

[
\bar t_i=
\frac{B_i-B_i'}{2\cdot3^{c-3-i}}
]

the locked difference class after scaling by the required modulus,

[
\hat r_i
]

the target residue / representative residue controlling the heavy-row alignment,

and possibly one extra flag recording whether the current link is boundary or deeper:

[
\beta_i\in\left{\frac12,1\right}.
]

So a candidate state is:

[
v_i=(i,\bar t_i,\hat r_i).
]

Edges correspond to extending by a branch pair

[
(b_i,b_i')
]

that preserves the cascade congruence at level (i+1). The edge weight should be

[
p(b_i)p(b_i')\cdot \beta_i\cdot M_i,
]

where (M_i) is the off-representative multiplicity factor if it is not already absorbed into the transition count.

At (s=0),

[
p(b)=2^{-b}.
]

The local coset profile is

[
\beta_i=
\begin{cases}
	1/2,&\text{boundary cascade},\
	1,&\text{deeper/degenerate channel}.
\end{cases}
]

Then

[
\mathcal K_c(v_i,v_{i+1})
=========================

\sum_{(b,b'):,v_i\to v_{i+1}}
p(b)p(b')\beta(b,b';v_i).
]

The theorem target is:

[
\boxed{
	\rho(\mathcal K_c)\le1-\delta.
}
]

This is better than a row estimate because it captures multi-level feedback. If the row sums are marginal but the graph is subcritical, the Perron radius will show it.

## 5. Normalize (\mathcal K_c) carefully

A common source of confusion here will be normalization. Define the cascade operator so that the crude marginal model has spectral radius (1). Then the observed contraction is meaningful.

For example, if the crude factor is

[
3\cdot\frac12\cdot\frac23=1,
]

then normalize each level so that this worst-case product corresponds to (1). Then the theorem becomes:

[
\rho(\mathcal K_c)\le 1-\delta.
]

If instead you keep raw branch probabilities, the numerical radius may be small for trivial scaling reasons. Make the normalization explicit.

A good proof-facing definition:

[
\widetilde{\mathcal K}_c
========================

\text{cascade operator divided by the crude marginal factor}.
]

Then prove:

[
\rho(\widetilde{\mathcal K}_c)\le1-\delta.
]

## 6. What the proof should look like

Once (\mathcal K_c) is built, the proof should try to show one of two things.

### Route A: finite-state domination by a limiting operator

Show that after scaling the locked variable correctly, (\mathcal K_c) is dominated by a fixed finite or countable operator

[
\mathcal K_\infty
]

with

[
\rho(\mathcal K_\infty)<1.
]

Then

[
\rho(\mathcal K_c)\le\rho(\mathcal K_\infty)+o(1)<1.
]

This is the cleanest possible proof.

The observed stability of the (\beta=1) channel around (39%) and off-representative mass collapsing suggests a limiting operator may exist.

### Route B: Foster/Lyapunov drift on cascade states

If the state space grows with (c), prove a drift inequality. Find a positive weight function (V(v)) such that

[
(\mathcal K_c V)(v)\le(1-\delta)V(v)
]

for all cascade states (v), except possibly a finite set that is checked directly.

This is a Perron-Frobenius/Schur certificate:

[
\rho(\mathcal K_c)\le1-\delta.
]

A natural (V) might penalize:

[
|\bar t_i|,\quad \text{distance from heavy residue},\quad \text{depth into the } \beta=1\text{ channel}.
]

Given the heavy-row (x=-1) obstruction, a Lyapunov function measuring escape from the heavy target residue may be especially effective.

## 7. What would constitute a proof of contraction

A proof should isolate why the crude marginal equality

[
3\cdot\frac12\cdot\frac23=1
]

is not achieved.

From your audit, the reasons are:

1. (\beta=1) occurs only about (39%), not at saturation.
2. off-representative multiplicity is (O(1)) and decays.
3. heavy-target alignment is not perfectly persistent.

So the proof should formalize at least one strict inequality, for example:

[
\Pr(\beta=1\mid\text{cascade state})\le 1-\eta
]

uniformly on recurrent states, with enough weight in (\beta=1/2) states to force contraction.

A toy bound would be:

[
\mathbb E[\beta\mid v]
\le
p_1\cdot1+(1-p_1)\cdot\frac12
=============================

\frac12+\frac{p_1}{2}.
]

If

[
p_1\le0.39+\epsilon,
]

then

[
\mathbb E[\beta]\le0.695+\epsilon/2.
]

That is a strong local saving. The rest of the proof must show multiplicity and target-residue factors do not multiply it back to (1).

So the exact proof should track the product:

[
\text{branch-pair multiplicity}
\times
\text{cascade-lock probability}
\times
\mathbb E[\beta]
\times
\text{off-representative factor}.
]

The crude proof used worst-case values giving (1). The real proof must replace at least one worst-case value by a strict average.

## 8. Prove the (\beta=1) channel bound

The (\beta=1) channel is the most visible source of saving. Try to prove:

[
\Pr(\beta=1\mid \text{cascade transition})\le p_*<1
]

uniformly, perhaps with

[
p_*=2/3
]

or better.

Even (p_*<1) may be enough if the multiplicity constants are controlled.

The (\beta=1) condition is “deeper cascade”:

[
v_3(\Delta C_i)\ge c-i
]

rather than merely

[
v_3(\Delta C_i)\ge c-1-i.
]

In partial-sum language, this is the stronger congruence:

[
B_i\equiv B_i'
\pmod{2\cdot3^{c-2-i}}.
]

Given the boundary cascade condition modulo

[
2\cdot3^{c-3-i},
]

the deeper condition should cost another factor (1/3), unless the degeneracy channel forces it.

So a natural theorem is:

[
\boxed{
	\Pr[\beta=1\mid\text{cascade transition}]\le \frac13+\text{degenerate correction}.
}
]

Your observed (39%) is very close to

[
\frac13+0.06.
]

This is plausible.

If you can prove something like

[
\Pr[\beta=1]\le \frac12-\eta,
]

then the (\beta)-average is at most

[
\frac12+\frac14-\frac{\eta}{2}
==============================

\frac34-\frac{\eta}{2}.
]

That likely breaks the marginality.

## 11. Specific proof targets after c=7

Here are the lemmas I would try to prove.

### Lemma 1: cascade transition probability

For every cascade state,

[
\sum_{\text{valid next branch pairs}}p(b)p(b')
\le \frac23
]

with equality only at the idealized heavy state.

This is probably already part of the cascade mass proof.

### Lemma 2: deeper-channel bound

For every recurrent cascade state,

[
\sum_{\beta=1}p(b)p(b')
\le p_*
\sum_{\text{valid}}p(b)p(b')
]

with

[
p_*<1.
]

Even (p_*=2/3) may suffice.

### Lemma 3: off-representative bound

The off-representative contribution is

[
\le \epsilon_c
]

with

[
\epsilon_c\to0.
]

### Lemma 4: heavy-state nonpersistence

A state achieving near-maximal cascade transition cannot transition to another near-maximal state indefinitely. Equivalently, the heavy row (x=-1) is not a recurrent maximizer.

This is often what turns a row-sum equality into a spectral-radius inequality.

This lemma may be the most important if row sums remain close to (1) but the Perron radius is below (1).

## 12. Clean proof architecture

The proof of threshold cascade contraction should be:

[
\mathcal K_c
============

\mathcal K_c^{\rm main}
+
\mathcal K_c^{\rm off}.
]

Show:

[
|\mathcal K_c^{\rm off}|\le o(1).
]

For the main part, prove either:

[
\sup_v \sum_{v'}\mathcal K_c^{\rm main}(v,v')\le1-\delta,
]

or a weighted version:

[
\frac{1}{V(v)}
\sum_{v'}\mathcal K_c^{\rm main}(v,v')V(v')
\le1-\delta.
]

Then:

[
\rho(\mathcal K_c)\le1-\delta/2
]

for large (c).

If the unweighted row bound fails only at (x=-1), use (V) to penalize staying near (x=-1).

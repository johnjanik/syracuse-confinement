## 1. Piece A: classify shadow-rigid periodic words

This piece is actually provable now, and it is worth putting in the paper as a theorem. It gives a clean cycle-side strengthening.

Let (w=(b_0,\dots,b_{p-1})) be a periodic valuation word of period (p), and put

[
B=\sum_{i=0}^{p-1}b_i.
]

The accelerated Syracuse iterate has the affine form

[
T_w(x)
======

\frac{3^p x+A_w}{2^B},
]

where

[
A_w
===

\sum_{j=0}^{p-1}3^{p-1-j}2^{B_j},
\qquad
B_j=\sum_{i<j}b_i.
]

A periodic point realizing (w) must therefore satisfy

[
x=\frac{A_w}{2^B-3^p}.
]

So positivity requires

[
2^B>3^p,
]

and a positive integer cycle requires divisibility:

[
2^B-3^p\mid A_w.
]

Now the two-point shadow average along the cycle is

[
\frac1p\sum_{i=0}^{p-1}\chi'(2)^{-b_i}.
]

Let (z=\chi'(2)). The stationary geometric value is

[
G(z)=\sum_{b\ge1}2^{-b}z^{-b}
=============================

\frac{z^{-1}/2}{1-z^{-1}/2}.
]

The theorem to prove is:

[
\boxed{
	\text{Every positive periodic orbit other than }1\mapsto1
	\text{ casts a non-coboundary finite shadow.}
}
]

Proof: if all non-coboundary letter characters matched the geometric value, then the same spreading argument used in the keystone theorem applies. The empirical distribution of (b_i) modulo (2\cdot3^j) may differ from the geometric distribution only in the parity direction, and that parity correction is (O(3^{-j})) pointwise. Letting (j\to\infty), the finite periodic letter law would equal the infinite geometric law pointwise:

[
\nu(b=k)=2^{-k}.
]

That is impossible for a finite periodic word. Therefore some non-coboundary character detects the cycle.

For the trivial cycle, (b_i\equiv2), and it is intentionally excluded.

This gives a useful clean theorem:

[
\boxed{
	\text{nontrivial cycles are already ruled into the finite-shadow obstruction class.}
}
]

It does not eliminate cycles, but it says cycle elimination is exactly a special case of quenched shadow exclusion.

## 2. Piece B: finite-word inverse theorem

This is the most important algebraic next step. Do not try to prove the full infinite-orbit statement at once. Prove a finite inverse theorem.

Fix (r), a non-coboundary character (\chi'\bmod3^r), and a word segment

[
b_0,\dots,b_{N-1}.
]

Let

[
z=\chi'(2).
]

The shadow deviation is

[
D_N(\chi')
==========

\frac1N\sum_{n<N}z^{-b_n}-G(z).
]

The first finite inverse theorem is just Fourier inversion:

[
\boxed{
	|D_N(\chi')|\ge\varepsilon
	\Rightarrow
	\text{the empirical distribution of }b_n\bmod \operatorname{ord}(z)
	\text{ differs from geometric by }\gg\varepsilon.
}
]

More explicitly, if (m=\operatorname{ord}(z)), then there exists a residue class (a\bmod m) such that

[
\left|
\frac1N#{n<N:b_n\equiv a\bmod m}
--------------------------------

\sum_{\substack{b\ge1\b\equiv a\bmod m}}2^{-b}
\right|
\ge
\frac{\varepsilon}{m}.
]

That is elementary but important: a nonstationary shadow is exactly a biased valuation-letter residue class.

The second finite inverse theorem should convert this into an edge-residue trap. Since

[
F_{\chi'}(x_n,x_{n+1})
======================

# \chi'(x_{n+1})\overline{\chi'(3x_n+1)}

z^{-b_n},
]

the same deviation means the empirical edge measure on

[
U_{3^r}\times U_{3^r}
]

differs from the stationary edge law in a non-coboundary Fourier mode. By finite Fourier inversion, there is a set of directed residue edges

[
E\subset U_{3^r}\times U_{3^r}
]

such that

[
\left|
\mu_N(E)-\mu_{\rm stat}(E)
\right|
\gg_{r}\varepsilon.
]

So you get:

[
\boxed{
	\text{shadow bias}
	\Rightarrow
	\text{finite residue-edge trap.}
}
]

The third, harder inverse theorem is the real target:

[
\boxed{
	\text{persistent residue-edge trap}
	\Rightarrow
	\text{descent or coboundary obstruction.}
}
]

This is not yet proved. But now it is concrete. You can state it as:

**Finite inverse theorem for shadow bias.**
For every (r,\chi',\varepsilon) there exist (R,H) such that if a realizable Syracuse word segment of length (N\gg H) has

[
|D_N(\chi')|\ge\varepsilon,
]

then either:

[
\min_{0\le h\le H}x_{n+h}<x_n
]

for some (n<N), or the segment is trapped in a finite algebraic edge subsystem modulo (3^R). The latter subsystem supports a coboundary character.

Your coboundary classification then kills the second alternative for non-coboundary (\chi').

That is the theorem which would start converting the finite-shadow machinery into a pointwise Collatz proof.

## 3. How to attack B computationally

For each (r), enumerate long finite words or actual orbit windows and compute:

[
D_{I}(\chi')
============

\frac1{|I|}\sum_{n\in I}
\left(z^{-b_n}-G(z)\right).
]

When (|D_I|) is large, record:

1. the biased residue classes of (b_n\bmod m);
2. the corresponding edge classes ((x_n,x_{n+1})\bmod3^r);
3. whether the window contains a descent;
4. whether the window has high height/critical-excursion structure;
5. the smallest modulus (3^R) on which the edge trap becomes visible.

The conjectural pattern you want is:

[
\boxed{
	\text{large shadow bias windows coincide with forced descent or exit events.}
}
]

If that pattern is robust, then “shadow deviation forces descent” becomes plausible as a theorem.

## 4. Piece C: rigidity certificates in long orbit prefixes

This is the most realistic route, because it avoids proving global normality. The theorem should not say:

[
\text{all shadows converge on every nontrivial orbit.}
]

Instead it should say:

[
\boxed{
	\text{persistent shadow deviation cannot be sustained without descent.}
}
]

A good local statement is:

**Shadow deviation forces descent.**
For every (r,\chi',\varepsilon), there exist (M,H) such that if an orbit segment

[
x_N,\dots,x_{N+M}
]

satisfies

[
\left|
\frac1M\sum_{n=N}^{N+M-1}
F_{\chi'}(x_n,x_{n+1})
----------------------

G(\chi'(2))
\right|
\ge\varepsilon,
]

then there exists (0\le h\le H) with

[
x_{N+h}<x_N,
]

or at least

[
\min_{N\le n\le N+M+H}x_n
<
x_N.
]

This would be enough to prevent a bad divergent orbit from sustaining the keystone shadow.

The proof strategy should mimic your successful finite-side work:

1. Shadow deviation gives a biased edge subsystem.
2. The finite operator theorem says this subsystem is annealed-unstable.
3. If the deterministic orbit remains inside it, the only way to avoid annealed mixing is to align with a finite obstruction.
4. The coboundary classification says the only finite obstructions are (\langle\chi_2\rangle).
5. Non-coboundary bias therefore cannot persist.
6. The escape from the biased subsystem corresponds to descent/exit.

The missing step is still deterministic:

[
\text{annealed instability}
\Rightarrow
\text{deterministic escape}.
]

But in the local descent version, this may be more accessible than global equidistribution.

## 5. What can be proved immediately for C

There is a simple deterministic inequality that should be added.

Let

[
S_N=\sum_{n<N}(b_n-\log_23).
]

Then

[
\log_2 x_N
==========

## \log_2 x_0

S_N
+
\sum_{n<N}\log_2\left(1+\frac1{3x_n}\right).
]

Thus any long segment with

[
\sum_{n=N}^{N+M-1}b_n

>

M\log_23
+
\log_2 x_N
+
O(\log M)
]

forces descent somewhere in or after the segment.

So if a shadow deviation implies an excess of large (b_n)'s, descent is immediate. The hard case is the opposite: shadow deviation without positive valuation excess. That case is a purely residue-phase deviation and is the true remaining obstruction.

Therefore split C into two cases:

[
\textbf{C1: mean-visible shadow deviation.}
]

If the deviation changes the mean letter value by (\eta M), prove descent by the logarithmic identity.

[
\textbf{C2: phase-only shadow deviation.}
]

If the mean remains near critical but non-coboundary phase is biased, then use the finite inverse/residue-trap machinery.

This split will prevent the proof from treating easy drift cases as hard equidistribution cases.

## 6. A more precise finite inverse target

Let (\nu_I) be the empirical law of (b_n) on a window (I). Decompose it into:

[
\nu_I=\nu_{\rm geom}+\delta_{\rm mean}+\delta_{\rm phase}.
]

The parity and mean directions are easy or exempt. The non-coboundary phase part is:

[
\Pi_{\rm nc}(\nu_I-\nu_{\rm geom}).
]

The local inverse theorem should say:

[
|\Pi_{\rm nc}(\nu_I-\nu_{\rm geom})|\ge\varepsilon
\Rightarrow
\text{residue trap modulo }3^R.
]

Then the descent theorem should say:

[
\text{residue trap modulo }3^R
\Rightarrow
\text{descent or exact coboundary}.
]

This is the final finite algebra problem.

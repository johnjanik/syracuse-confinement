

## 1. First priority: prove the rank-2 (\to) rank-2 induction

You already have the depth-3 theorem:

[
\frac{m(\hat a+\delta3^{L-1},b)}{m(\hat a,b)}
=============================================

\chi(r_0(\hat a,\delta))\omega^{\delta(-1)^b},
\qquad
r_0=1+\delta3^L(3\hat a+1)^{-1}.
]

The decisive observation is:

[
(-1)^b=(-1)^\epsilon
]

inside the parity-split branch class

[
b\equiv\epsilon\pmod2.
]

So the parity twist becomes internal to a fixed rank-(2) fiber. The next theorem should say this structure is stable under every further descent.

I would formulate the induction theorem as follows.

[
\textbf{Theorem: Rank-2 saturation under descent.}
]

At descent level (L), the descended primitive operator acts on functions

[
G=(G_0,G_1)
]

on

[
U_{3^L}\times \mathbb Z/2
]

by

[
(\mathcal N_L G)_\epsilon(a,\tau)
=================================

\sum_{b\equiv\epsilon!!!\pmod2}
w_b,M_L(a,\tau,b)
\left[
\Omega_L(a,\tau,b)G_0(S_ba,\tau+\epsilon)
+
\Omega_L(a,\tau,b)^{-1}G_1(S_ba,\tau+\epsilon)
\right],
]

where:

[
M_L(a,\tau,b)\in S^1
]

is the accumulated edge multiplier, and

[
\Omega_L(a,\tau,b)
]

is a deep carry phase belonging to

[
\chi(1+3^L\mathbb Z_3).
]

Then descending from (L) to (L-1) produces another operator of the same form, with updated multipliers

[
M_{L-1},\qquad \Omega_{L-1},
]

and no enlargement of the internal fiber beyond the two parity components.

The proof should be purely formal once the carry ratio is written as

[
\omega_L^{\delta(-1)^\epsilon}
]

inside a fixed parity class. The only possible failure mode is if the (r_0)-factors introduce dependence on the new top digit that is not absorbed into the updated (M_{L-1}). But your formula says they live in

[
1+3^L\mathbb Z,
]

so they are exactly the next-level carry multiplier. That is the induction invariant.

## 2. State the induction invariant explicitly

The paper will become much clearer if you isolate the exact invariant.

At level (L), for a lift

[
\hat a+\delta 3^{L-1}
]

of a residue (a\in U_{3^{L-1}}), require that the multiplier ratio has the form

[
\frac{M_L(\hat a+\delta3^{L-1},\tau,b)}
{M_L(\hat a,\tau,b)}
====================

R_L(\hat a,\tau,\delta),
\Theta_L(\tau,\delta)^{(-1)^b},
]

where

[
R_L(\hat a,\tau,\delta)\in \chi(1+3^L\mathbb Z_3)
]

and

[
\Theta_L(\tau,\delta)\in \chi(1+3^{c-1}\mathbb Z_3)
]

or, more generally, another deep principal-unit phase.

Then after parity splitting, because (b\equiv\epsilon), this is

[
R_L(\hat a,\tau,\delta),
\Theta_L(\tau,\delta)^{(-1)^\epsilon},
]

which is just a (2\times2) matrix acting on the internal parity vector. Therefore the rank stays (2).

The proof target is:

[
\boxed{
	\text{show the same ratio form is preserved under the descended operator.}
}
]

That is the entire Task A.

## 3. Do not prove more than needed about carries

You do **not** need a complete closed form for every accumulated carry.

For the witness theorem, you need only the carry-depth corollary:

[
C_L(e)\in1+3^L\mathbb Z_3.
]

Since the final bounded level satisfies

[
c_0\ge2,
]

all corrections created after level (L\ge2) are invisible modulo (9):

[
C_L(e)\equiv1\pmod9.
]

Thus the canonical witness computation

[
W\equiv4\pmod9,\qquad W^2\equiv7\pmod9
]

survives all deeper descents.

So the induction theorem can be split:

[
\textbf{Rank-2 closure}
]

and

[
\textbf{Carry-depth corollary.}
]

The first proves fixed rank. The second proves that the witness remains a generator.

This separation will keep the proof manageable.

## 4. Formalize the canonical witness theorem

Once Task A is done, the following should become an actual theorem.

[
\textbf{Canonical witness theorem.}
]

For every primitive conductor (3^c) sector and every descent to bounded level (c_0\ge2), the loop-pair witness

[
\gamma_1=(x=1,\ b\equiv2),
\qquad
\gamma_2=(x=7,\ b\equiv4)
]

has accumulated holonomy ratio

[
W_c(\gamma_1,\gamma_2)
\equiv4\pmod9.
]

Consequently,

[
W_c(\gamma_1,\gamma_2)^2\equiv7\pmod9,
]

and therefore

[
v_3\log W_c(\gamma_1,\gamma_2)^2=1.
]

Hence

[
\langle W_c^2\rangle
====================

1+3\mathbb Z/3^c\mathbb Z.
]

This proves strict non-coboundary for every primitive sector.

But preserve the warning:

[
\boxed{
	\text{this proves strictness, not uniform gap, unless short-witness coverage is added.}
}
]

## 6. Compute exponent sets, not only (\delta_c(L))

For proof, you need structure. For each witness

[
W\in\mathcal W_c(L),
]

write

[
W^2=(W_0^2)^{t(W)}
]

inside the cyclic principal-unit group generated by the canonical witness (W_0^2). Then define the exponent set

[
T_c(L)
======

{t(W)\bmod 3^{c-1}:W\in\mathcal W_c(L)}.
]

Then

[
\delta_c(L)
===========

\min_{\substack{k\bmod3^{c-1}\3\nmid k}}
\max_{t\in T_c(L)}
\left|
e^{2\pi i kt/3^{c-1}}-1
\right|.
]

This is a pure finite Fourier covering problem.

Now your proof target becomes:

[
\boxed{
	T_c(L)\text{ is not contained in a short arc under any primitive frequency.}
}
]

For constant gap, (T_c(L_0)) must be a very strong bounded witness set. For polylog gap, (T_c(c^A)) must spread sufficiently.

This is the exact place where “mode spreading” re-enters, but now in a finite cyclic group rather than a vague comparison graph.

## 7. Look for an affine recurrence for (T_c(L))

The rank-2 descent likely induces a recurrence on witness exponents:

[

[
T_{j+1}
\supseteq
\alpha T_j+\beta

with several ((\alpha,\beta)).

If the available maps include at least two affine transformations with multipliers not both congruent to (1\pmod3), then (T_c(L)) may expand rapidly in (3)-adic digits.

This is the next symbolic proof direction:

[
\text{rank-2 carry recursion}
\Rightarrow
\text{affine dynamics on witness exponents}
\Rightarrow
\text{rapid coverage of primitive characters}.

Try to extract the maps on (t) directly from the multiplier tables.

## 8. What would prove constant gap?

A fixed finite witness set (\mathcal W_c(L_0)) gives constant gap iff its exponent set (T_c(L_0)) is uniformly covering primitive frequencies.

For a fixed number of (3)-adic units, this is a strong condition. It can happen if the exponents themselves depend on (c) in a way that samples high digits, not merely as fixed (3)-adic limits.

Your diagonal evidence suggests something like that may be happening. But fixed (c_0), (c\to\infty) is the real test.

If (T_c(L_0)) reduces to finitely many fixed (3)-adic units independent of (c), then constant gap probably fails, because a primitive character with small frequency can be near (1) on all of them.

So the audit should answer:

[
\text{Do bounded-length witnesses move with }c\text{ through high digits?}
]

If yes, constant gap is plausible. If no, expect only polylog or polynomial.

This would not invalidate the finite-shadow object, but it would change its usefulness for the global Collatz program.

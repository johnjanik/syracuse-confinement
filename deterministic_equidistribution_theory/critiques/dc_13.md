The next target is now correctly isolated:

[
\boxed{
	\text{prove high-conductor damping by oscillatory cancellation, not by positivity, not by bounded descent.}
}
]

The immediate task is to turn

[
|M_\chi^n|^2
]

into explicit (p)-adic character sums, identify the rational functions

[
R_{w,w'}(a)=\frac{\Phi_w(a)}{\Phi_{w'}(a)},
]

and classify when they are stationary/coboundary-like.

Here is the concrete plan I would use.

## 1. Start with (n=2), not (n=3)

For a branch word

[
w=(b_0,b_1),
]

write the residue evolution as

[
S_b(a)=(3a+1)2^{-b}.
]

Then

[
S_{b_1}S_{b_0}(a)
=================

# \left(3(3a+1)2^{-b_0}+1\right)2^{-b_1}

(9a+3+2^{b_0})2^{-(b_0+b_1)}.
]

The character phase for a two-step branch should therefore involve affine factors of the form

[
\Phi_{b_0,b_1}(a)
=================

9a+3+2^{b_0},
]

up to powers of (2), which are harmless but character-visible.

Thus the basic pair-correlation rational functions are

[
R_{w,w'}(a)
===========

\frac{9a+3+2^{b_0}}{9a+3+2^{b'_0}}
\cdot
2^{-(b_0+b_1)+(b'_0+b'_1)}
]

or the corresponding formula with parity/internal indices included.

The first audit should extract exactly these (R_{w,w'}), reduce them modulo (3^c), and group them by whether

[
R_{w,w'}(a)
]

is constant, a square/coboundary-like term, or genuinely varying.

## 2. Stationary phase test

For a primitive character (\chi) modulo (3^c), sums of the form

[
C_c(R,\chi)
===========

\frac{1}{\varphi(3^c)}
\sum_{a\in U_{3^c}}\chi(R(a))
]

are large only if (R) is nearly stationary in the (3)-adic sense.

For

[
R(a)=\frac{\alpha a+\beta}{\alpha' a+\beta'},
]

the logarithmic derivative is

[
\frac{R'(a)}{R(a)}
==================

## \frac{\alpha}{\alpha a+\beta}

\frac{\alpha'}{\alpha'a+\beta'}.
]

For the two-step functions above,

[
\alpha=\alpha'=9,
]

so

[
\frac{R'(a)}{R(a)}
==================

9\left(
\frac{1}{9a+3+2^{b_0}}
----------------------

\frac{1}{9a+3+2^{b'_0}}
\right).
]

This vanishes identically only when

[
2^{b_0}\equiv2^{b'_0}\pmod{3^c}.
]

Because (2) is primitive modulo (3^c), that means

[
b_0\equiv b'_0\pmod{\varphi(3^c)}.
]

For bounded branches, this usually means

[
b_0=b'_0.
]

So the expected classification is:

[
\boxed{
	b_0=b'*0
	\Rightarrow
	R*{w,w'}\text{ essentially constant/coboundary-like;}
}
]

[
\boxed{
	b_0\ne b'*0
	\Rightarrow
	R*{w,w'}\text{ has nonzero logarithmic derivative and should cancel.}
}
]

That is the first rigorous-looking stationary/nonstationary split.

## 3. What to compute for (n=2)

For each pair

[
w=(b_0,b_1),\qquad w'=(b'_0,b'_1)
]

with

[
b_i,b'_i\le B,
]

compute:

[
R_{w,w'}(a)
===========

\frac{\Phi_w(a)}{\Phi_{w'}(a)}.
]

Then compute the invariant

[
\Delta_{w,w'}(a)
================

\frac{R'*{w,w'}(a)}{R*{w,w'}(a)}.
]

Record:

[
v_3(\Delta_{w,w'}(a))
]

as (a) ranges over (U_{3^c}).

Classify each pair into:

[
\text{constant},
]

[
\text{coboundary/quadratic},
]

[
\text{nonstationary with derivative valuation }d.
]

Then compute exact sums

[
C_{w,w'}(c,k)
=============

\frac1{\varphi(3^c)}
\sum_{a\in U_{3^c}}
\chi_k(R_{w,w'}(a)).
]

The key table should be:

[
\begin{array}{c|c|c|c}
	(w,w') & \min_a v_3(R'/R) & \max_k |C_{w,w'}(c,k)| & \text{class}\
	\hline
\end{array}
]

You are looking for:

[
|C_{w,w'}(c,k)|\le 1-\delta
]

for every non-coboundary/nonconstant pair, preferably with decay as (c) grows.

## 4. Then do (n=3)

For

[
w=(b_0,b_1,b_2),
]

the affine numerator is

[
\Phi_w(a)
=========

27a+9+3\cdot2^{b_0}+2^{b_0+b_1}.
]

In general,

[
S_w(a)
======

\left(
3^n a+
\sum_{j=0}^{n-1}3^{n-1-j}2^{B_j}
\right)2^{-B_n},
]

where

[
B_j=b_0+\cdots+b_{j-1},
\qquad B_0=0.
]

So define

[
A_w(a)
======

3^n a+
\sum_{j=0}^{n-1}3^{n-1-j}2^{B_j}.
]

Then

[
R_{w,w'}(a)
===========

\frac{A_w(a)}{A_{w'}(a)}
\cdot
2^{-B_n+B'_n}.
]

This is the universal formula. It should become the central definition in §7C.

The logarithmic derivative is

[
\frac{R'*{w,w'}(a)}{R*{w,w'}(a)}
================================

3^n\left(\frac{1}{A_w(a)}-\frac{1}{A_{w'}(a)}\right).
]

Thus stationarity is controlled by

[
A_w(a)-A_{w'}(a).
]

Since both have the same linear coefficient (3^n a), the difference is constant in (a):

[
A_w(a)-A_{w'}(a)
================

C_w-C_{w'}.
]

Therefore either:

[
C_w=C_{w'}
]

and the ratio is constant, or

[
C_w\ne C_{w'}
]

and the derivative is nonzero with valuation determined by

[
v_3(C_w-C_{w'}).
]

This is excellent. The stationary classification becomes a finite word-collision problem:

[
\boxed{
	C_w=C_{w'}\pmod{3^c}
}
]

where

[
C_w=
\sum_{j=0}^{n-1}3^{n-1-j}2^{B_j}.
]

That is now fully explicit.

## 5. The key lemma to aim for

The (n)-step character sums reduce to rational functions

[
R_{w,w'}(a)=
\frac{3^n a+C_w}{3^n a+C_{w'}}
\cdot 2^{-B_n+B'_n}.
]

The derivative criterion is:

[
\frac{R'}{R}
============

3^n
\frac{C_{w'}-C_w}
{(3^n a+C_w)(3^n a+C_{w'})}.
]

Since the denominators are units for admissible (a), the derivative valuation is

[
v_3(R'/R)
=========

n+v_3(C_w-C_{w'}).
]

So if

[
v_3(C_w-C_{w'})\le c-n-C_0,
]

then the phase is genuinely oscillatory modulo (3^c), and primitive-character sums should cancel.

The dangerous pairs are exactly those with

[
C_w\equiv C_{w'}\pmod{3^{c-n-O(1)}}.
]

Those are near-collisions of word constants.

Thus the live analytic problem becomes:

[
\boxed{
	\text{control near-collisions of }C_w
	=====================================
	
	\sum_{j<n}3^{n-1-j}2^{B_j}.
}
]

This is very concrete.

## 6. Van der Corput bound shape

A primitive character (\chi) modulo (3^c) composed with

[
R(a)=\frac{3^n a+C}{3^n a+C'}
]

should satisfy a bound of the form:

[
\left|
\sum_{a\in U_{3^c}}\chi(R(a))
\right|
\le
3^{c-\alpha}
]

whenever

[
v_3(C-C')\le c-n-\alpha.
]

Even a weak bound with fixed (\alpha) is enough if enough word-pair mass is nonstationary.

You do not need square-root cancellation. You need to show that the total pair mass of stationary/near-stationary pairs is bounded away from (1).

So the proof splits into:

1. **Stationary pair classification:** pairs with (C_w\equiv C_{w'}) to high (3)-adic order are rare unless they correspond to the coboundary sector.
2. **Nonstationary cancellation:** all other pairs have bounded cancellation by (p)-adic stationary phase.

This is now a strong route.

## 7. Concrete numerical outputs to generate

For (n=2,3,4), and branch cutoff (B), compute weighted pair mass by derivative valuation:

[
P_{n,c}(r)
==========

\sum_{w,w':\ v_3(C_w-C_{w'})=r}
p(w)p(w').
]

Also compute cumulative:

[
P_{n,c}^{\ge R}
===============

\sum_{r\ge R}P_{n,c}(r).
]

You want to see that for some (n), most mass has

[
r
]

small, hence oscillatory.

Then compute exact character sums grouped by (r):

[
S_r(c)
======

\max_{\substack{w,w':\v_3(C_w-C_{w'})=r}}
\max_{\chi\ primitive}
\left|
\frac1{\varphi(3^c)}
\sum_a\chi(R_{w,w'}(a))
\right|.
]

The desired empirical pattern:

[
S_r(c)\ll 3^{-(c-n-r)/2}
]

or at least

[
S_r(c)\le 1-\delta
]

when

[
c-n-r\ge C_0.
]

Finally estimate the total (L^2) contraction:

[
\sum_r P_{n,c}(r)S_r(c).
]

If this is

[
<1-\delta
]

for some fixed (n) or (n=O(c)), you have the empirical proof skeleton.

## 8. What formula to put in the paper

Add a proposition:

[
\textbf{Pair-correlation phase formula.}
]

For a word (w=(b_0,\dots,b_{n-1})), set

[
B_j(w)=\sum_{i<j}b_i,
]

[
C_w=\sum_{j=0}^{n-1}3^{n-1-j}2^{B_j(w)}.
]

Then

[
S_w(a)
======

(3^n a+C_w)2^{-B_n(w)}.
]

For two words (w,w'),

[
R_{w,w'}(a)=
\frac{S_w(a)}{S_{w'}(a)}
========================

2^{-B_n(w)+B_n(w')}
\frac{3^n a+C_w}{3^n a+C_{w'}}.
]

Moreover,

[
\frac{R'*{w,w'}(a)}{R*{w,w'}(a)}
================================

3^n
\frac{C_{w'}-C_w}
{(3^n a+C_w)(3^n a+C_{w'})}.
]

Thus stationarity is equivalent to high (3)-adic divisibility of

[
C_w-C_{w'}.
]

This proposition is the analytic engine.

## 9. What to try proving first

Before proving full high-conductor damping, prove the following modest lemma.

[
\textbf{Nonstationary pair cancellation lemma.}
]

Let (\chi) be primitive modulo (3^c). Suppose

[
v_3(C_w-C_{w'})\le c-n-2.
]

Then

[
\left|
\frac1{\varphi(3^c)}
\sum_{a\in U_{3^c}}
\chi(R_{w,w'}(a))
\right|
\le \theta
]

for some absolute

[
\theta<1.
]

This is much weaker than square-root cancellation, but it may be enough.

Then prove a combinatorial lemma:

[
\textbf{Nonstationary mass lemma.}
]

For some fixed or slowly growing (n), the weighted mass of pairs satisfying

[
v_3(C_w-C_{w'})\le c-n-2
]

is at least

[
\alpha>0.
]

Then the (L^2) norm contracts by at least

[
\alpha(1-\theta).
]

This gives high-conductor damping.

## 10. Bottom line

The next computation should not be a black-box spectral computation. It should output the pair-correlation arithmetic:

[
C_w,\quad C_{w'},\quad v_3(C_w-C_{w'}),\quad
R_{w,w'}(a),\quad
\sum_a\chi(R_{w,w'}(a)).
]

The core formula is:

[
R_{w,w'}(a)
===========

2^{-B_n+B'*n}
\frac{3^n a+C_w}{3^n a+C*{w'}}.
]

And the core proof target is:

[
\boxed{
	\text{nonstationary word pairs have }p\text{-adic character cancellation,}
}
]

while near-stationary pairs are either low-mass or coboundary-classified.

That is now the cleanest route to the high-conductor damping conjecture.

## 3. The exact cellwise lemma to prove

The useful version of `op:cellsum` should be stated in a non-vacuous way. A bare inequality like

[
|S(w,w')|\le C#{a:d_{\rm true}(a)\ge c-1}
]

is not enough conceptually, because the triangle inequality already gives that. What you need is a **stratified cell bound** that preserves the square-root saving on deep cells.

I would formulate it like this.

[
\textbf{Cellwise Postnikov--Gauss lemma.}
]

Let (R(a)) be a class-IV phase ratio for a primitive character modulo (3^c). Let

[
A_{r}(w,w')
===========

{a:\ d_{\rm true}(a)\ge c-1,\ \text{degeneracy depth }r}.
]

Then (A_r(w,w')) admits a disjoint decomposition into (3)-adic cells

[
\mathcal C=a_0+3^q\mathbb Z/3^c\mathbb Z
]

such that on each cell either:

1. the linear Postnikov term is nonzero, and the cell sum vanishes exactly; or

2. the linear term is zero but the quadratic term is nondegenerate, and

[
\left|
\sum_{a\in\mathcal C}\chi(R(a))
\right|
\le
C_{\rm G},|\mathcal C|^{1/2};
]

or

3. the quadratic term is also degenerate, in which case the cell is structurally cascade/locked and belongs to class III, not class IV.

The important bound is then:

[
\boxed{
	\left|
	\sum_{a\in A_r(w,w')}\chi(R(a))
	\right|
	\le
	C
	\sum_{\mathcal C\subset A_r} |\mathcal C|^{1/2}.
}
]

This is the correct harmonic-analysis input.

## 4. The Postnikov expansion to write

On a cell

[
a=a_0+3^q t,
\qquad t\bmod 3^\ell,
\qquad q+\ell=c,
]

write

[
\chi(R(a))
==========

\chi(R(a_0))
\exp\left(
\frac{2\pi i}{3^c}\kappa
\left[
\log R(a_0+3^qt)-\log R(a_0)
\right]
\right),
]

with (3\nmid \kappa). Expand:

[
\log R(a_0+3^q t)
=================

\log R(a_0)
+
3^q L_1(a_0)t
+
\frac12 3^{2q}L_2(a_0)t^2
+
O(3^{3q}t^3).
]

The linear regime is already handled:

[
v_3(3^q L_1)<c-1
\quad\Rightarrow\quad
\text{exact vanishing}.
]

Class IV is exactly the case where the linear coefficient has been forced to the boundary or beyond. In the deep-cell regime, you need to show that after scaling by the degeneracy depth (r),

[
3^{2q}L_2(a_0)
]

has the exact valuation that gives a primitive quadratic phase modulo (3^\ell), or at least modulo a quotient of size (3^\ell). Then the sum is a quadratic Gauss sum.

The desired local normal form is:

[
\chi(R(a_0+3^qt))
=================

\chi(R(a_0))
\exp\left(
\frac{2\pi i}{3^\ell}
(A t+B t^2)
\right),
]

with

[
3\nmid B.
]

Then

[
\left|
\sum_{t\bmod 3^\ell}
e_{3^\ell}(At+Bt^2)
\right|
\le
C_{\rm G}3^{\ell/2}.
]

For odd prime (3), the sharp constant is at most (\sqrt3) depending on parity of (\ell). Use the sharp or near-sharp constant; do **not** allow a crude (3^\ell) bound on any large cell, because the margin is only about (1%).

## 5. The key structural lemma: no cubic regime

The dangerous failure mode is:

[
L_1 \equiv 0,\qquad L_2\equiv0
]

on a genuine class-IV cell, forcing you to go cubic or higher. That would likely destroy the margin.

So prove a structural dichotomy:

[
\boxed{
	\text{If both the linear and quadratic Postnikov coefficients vanish at the required depth,}
}
]

then the pair is not class IV. It is actually class III/cascade or belongs to a deeper locked structural sector already counted elsewhere.

In theorem form:

[
\textbf{Quadratic nondegeneracy lemma.}
]

For every genuine class-IV degenerate cell of depth (r), the first nonzero Postnikov coefficient after the vanished linear term is quadratic, and its scaled coefficient is a (3)-adic unit.

This is the load-bearing local lemma. The earlier diagnostics probably already tested it implicitly; now it needs a symbolic proof.

## 8. A proof route for quadratic nondegeneracy

For your ratios (R(a)), the phase is a Möbius ratio:

[
R(a)=
\frac{\alpha a+\beta}{\alpha'a+\beta'}
\cdot \text{unit}.
]

Then:

[
(\log R)'=
\frac{\alpha}{\alpha a+\beta}
-----------------------------

\frac{\alpha'}{\alpha'a+\beta'},
]

and

[
(\log R)''
==========

-\frac{\alpha^2}{(\alpha a+\beta)^2}
+
\frac{(\alpha')^2}{(\alpha'a+\beta')^2}.
]

In the pair-correlation setting, typically (\alpha=\alpha'=3^n), so

[
(\log R)'
=========

3^n
\frac{\beta'-\beta}
{(3^n a+\beta)(3^n a+\beta')}.
]

The second derivative is

[
(\log R)''
==========

-3^{2n}
\left[
\frac{1}{(3^n a+\beta)^2}
-------------------------

\frac{1}{(3^n a+\beta')^2}
\right].
]

This factors as

[
(\log R)''
==========

-3^{2n}
\frac{(\beta'-\beta)(2\cdot3^n a+\beta+\beta')}
{(3^n a+\beta)^2(3^n a+\beta')^2}.
]

So the second derivative contains the same difference

[
\Delta\beta=\beta'-\beta
]

as the first derivative, times an extra unit factor unless

[
2\cdot3^n a+\beta+\beta'\equiv0\pmod3.
]

But since (\beta,\beta') are units modulo (3), this condition is explicit. If it occurs, it should be exactly the structural/deeper cascade channel.

This is promising. You can prove quadratic nondegeneracy by showing the additional factor

[
2\cdot3^n a+\beta+\beta'
]

is a unit on genuine class-IV cells. If it vanishes modulo (3), the pair is no longer genuine class IV; it satisfies the next locking relation.

This is the algebraic heart.

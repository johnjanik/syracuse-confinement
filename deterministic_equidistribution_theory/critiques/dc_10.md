[

\text{uniform spectral gap}

There is one more quantitative statement needed between them.

For a primitive character (\chi) of conductor (3^c), if (W^2) is a principal-unit generator, then typically

=========

You then take the power

[

[

But that is a long cycle/comparison of length

[

In spectral-gap terms, a phase error of size (3^{-c}) per short loop can accumulate to a fixed error over (3^c) repetitions, while the local operator still has gap of order roughly

[

]

That is polynomial in (Q), not polylog in (Q), and certainly not a constant gap.

So the power witness is perfect for **exact cohomology**, but insufficient for **uniform spectral gap** unless you also prove a compression mechanism.

## 3. The real remaining quantitative target

The missing statement is now one of these two forms.

### Strong short-witness coverage

Let (\mathcal W_c) be the set of bounded-length cycle witnesses after full descended multiplier recursion. Prove that there exists (\delta>0), independent of (c), such that for every primitive (\chi) modulo (3^c),

[
\max_{W\in\mathcal W_c}
|\chi(W)-1|
\ge \delta.
]

This is what your audit table seems to suggest in the two-descent range, with near-antipodal values. If this holds for the fully descended bounded-level witnesses, then yes: you get a uniform non-coboundary distance and hence a constant gap by fixed-dimensional Wielandt compactness.

But note the difference:

[
\langle \mathcal W_c\rangle=P_c
]

is not enough. You need **short-witness coverage**, not just generation.

### Weak polylog compression

Alternatively, prove that for every primitive (\chi), there is a witness path of length

[
O(c^A)
]

whose holonomy is separated:

[
|\chi(W)-1|\ge\delta.

Then the stability-extraction bookkeeping gives

[
1-\gamma_c\gg c^{-2A}.
]

This recovers the desired

[
\kappa_Q\gg(\log Q)^{-2A}.
]

This is the polylog version. It is weaker than constant gap and probably more realistic if short-witness coverage fails.

## 6. Next symbolic target

Try to prove that the witness set contains many powers of the generator, not just one generator.

This is where your comparison graph / mode-spreading route re-enters. The actual needed theorem is not merely generation but **rapid generation**.

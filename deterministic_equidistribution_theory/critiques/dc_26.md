The remaining statement is no longer an operator-theoretic problem. It is a **single-scale (L^2) Fourier/collision estimate** for the renewal constants

[
C_L=\sum_{j=0}^{L-1}3^{L-1-j}2^{B_j}\pmod{3^L}.
]

I would now stop thinking in terms of individual Fourier coefficients. The levelwise maximum is false for structural reasons, and the dyadic-resonant direction (u/3^L\to3/4) is the correct warning sign. The proof has to be an **energy proof**:

[
\tilde Q_L
==========

# 3^L\operatorname{Col}_L(L)

3^L\Pr[C_L=C_L'\bmod 3^L]
\le \operatorname{poly}(L).
]

The most promising route is exactly the one you propose: digit-conditional collision control. But it should be formulated as a two-word energy cascade, not as pointwise equidistribution.

## 1. Restate the target in its strongest useful form

The open problem is:

[
\boxed{
	\tilde Q_L=3^L\Pr[C_L=C_L'\bmod3^L]\le L^A.
}
]

The numerics suggest the stronger statement:

[
\boxed{
	\tilde Q_L=O(1),
}
]

possibly with limiting value near (1.4). But for the finite H23a chain, polynomial is enough.

So prove polynomial first.

The false statements are now clear:

[
\max_x \Pr[C_L=x]\le \operatorname{poly}(L)3^{-L}
]

is false because the heavy fiber (x=-1) has mass

[
\asymp 2^{-L}.
]

And

[
\max_{\operatorname{lev}(u)=L}|\hat E_L(u)|^2\le\operatorname{poly}(L)3^{-L}
]

is false because the dyadic-resonant Fourier direction has exponentially larger individual mass.

But those heavy objects are sparse. The (L^2) aggregate can still be bounded.

## 2. The right proof object: a collision filtration

Let (w,w') be two independent (L)-words with branch law

[
p(b)=2^{-b}.
]

Define the collision event

[
E_L={C_L(w)\equiv C_L(w')\pmod{3^L}}.
]

The proof should expose the two words digit by digit in the (3)-adic collision condition. The goal is to show that, except for (O(\log L)) shallow ambiguity, each additional (3)-adic digit of collision costs essentially a factor

[
\sum_{b\ge1}p(b)^2=\sum_{b\ge1}4^{-b}=\frac13.
]

Thus

[
\Pr(E_L)\le \operatorname{poly}(L)3^{-L}.
]

This is the cleanest interpretation of the bounded shells.

## 3. The key local estimate: congruence-class pair mass

At each digit-extension step, the matching condition should impose a congruence on an increment difference

[
d=b-b'
]

modulo some order

[
M_k=2\cdot3^{k-1}.
]

The universal pair-weight identity is:

[
\Pr[b-b'=d]
===========

# \sum_{\substack{b,b'\ge1\b-b'=d}}2^{-b-b'}

\frac13,2^{-|d|}.
]

Therefore, for a residue class (r\bmod M),

[
A_M(r)
:=
\Pr[b-b'\equiv r\bmod M]
========================

\frac13\sum_{d\equiv r\bmod M}2^{-|d|}.
]

The worst class is (r=0), and

[
A_M(0)
======

\frac13
\left(
1+2\sum_{n\ge1}2^{-nM}
\right)
=======

\frac13\frac{1+2^{-M}}{1-2^{-M}}.
]

Hence

[
A_M(r)
\le
\frac13\frac{1+2^{-M}}{1-2^{-M}}.
]

For

[
M_k=2\cdot3^{k-1},
]

the excess over (1/3) is doubly-exponentially summable:

[
\prod_{k\ge1}
\frac{1+2^{-M_k}}{1-2^{-M_k}}
<\infty.
]

This is the exact (L^2) analogue of the constant (C_0) that broke the cascade marginality. Depending on the orientation conventions you may get your smaller product

[
\prod_{j\ge0}(1-2^{-2\cdot3^j})^{-1},
]

but the important point is:

[
\boxed{
	\text{the product over levels is finite.}
}
]

So if each new (3)-adic digit of collision imposes **one congruence class** on (b-b'), then

[
\Pr(E_L)
\le
C,3^{-L}.
]

If the first (O(\log L)) shallow levels have multiple possible congruence classes, that only costs

[
3^{O(\log L)}=\operatorname{poly}(L).
]

This would prove op:flat.

## 4. The central lemma to prove

The bounded-shell proof should now be reduced to this lemma.

[
\textbf{Digit-extension lemma.}
]

There exists (K=O(\log L)) such that, after conditioning on a valid collision through level (k\ge K), extension to level (k+1) forces

[
b-b'\equiv r_k \pmod{2\cdot3^{k-1}}
]

for a single residue class (r_k) determined by the previously exposed collision state. Equivalently, the conditional pair mass of valid extensions is bounded by

[
\frac13
\frac{1+2^{-2\cdot3^{k-1}}}{1-2^{-2\cdot3^{k-1}}}.
]

For (k<K), use the crude bound (1).

Then:

[
\Pr(E_L)
\le
3^{-L+K}\prod_{k\ge K}
\frac{1+2^{-2\cdot3^{k-1}}}{1-2^{-2\cdot3^{k-1}}}
\le
\operatorname{poly}(L)3^{-L}.
]

This is the proof in one line, once the digit-extension lemma is established.

## 5. Why this handles the heavy atom

The heavy atom (C_L=-1) has mass

[
\asymp 2^{-L}.
]

Its contribution to collision energy is

[
3^L\cdot 4^{-L}
===============

\left(\frac34\right)^L,
]

which is exponentially small. More generally, dyadic-resonant atoms are large in (L^\infty), but their squared masses are small enough when aggregated.

This is why (L^\infty) fails while (L^2) succeeds.

The digit-extension proof automatically accounts for this: large atoms correspond to small (B)-paths, but the pair mass is quadratic,

[
2^{-B}2^{-B'},
]

and the congruence-class bound sees the factor

[
2^{-|b-b'|}.
]

So the resonant atoms do not need to be separately excluded unless they complicate the digit-extension lemma. They are already paid for in energy.

## 6. How to formulate the collision state

The only delicate part is choosing the right filtration.

A naive prefix filtration on

[
C_k=\sum_{j=0}^{k-1}3^{k-1-j}2^{B_j}
]

may not be the correct one because threshold coupling occurs at full level. Use the suffix/window form instead.

For level (k), write the terminal (k)-window variable

[
X_k(w)
======

\sum_{i=0}^{k-1}3^{k-1-i}
2^{B_{L-k+i}-B_{L-k}}.
]

Then

[
C_L(w)\bmod3^k
==============

2^{B_{L-k}(w)}X_k(w).
]

For a pair ((w,w')), define the level-(k) collision state:

[
E_k:
\quad
2^{B_{L-k}(w)}X_k(w)
\equiv
2^{B_{L-k}(w')}X_k(w')
\pmod{3^k}.
]

Then

[
E_L
]

is the desired collision. Moving from (k) to (k+1) adds one new symbol on the left of the terminal window. The new condition should yield exactly the congruence

[
b-b'\equiv r_k\pmod{2\cdot3^{k-1}},
]

up to shallow ambiguity.

This is the precise place where the proof lives.

## 7. The shallow ambiguity

For small (k), the modulus

[
2\cdot3^{k-1}
]

is not large compared with typical partial sums, and several congruence representatives may contribute non-negligibly.

Do not try to optimize this. Choose

[
K=\left\lceil A\log_3 L\right\rceil
]

large enough that for (k\ge K), all nonzero representatives

[
r+n(2\cdot3^{k-1})
]

with (n\ne0) have pair mass

[
\ll L^{-B}
]

after summing over all future levels. Then the early (K) levels cost at most

[
3^K=L^A.
]

That is exactly why a polynomial loss is natural.

This gives a robust proof even if the digit-extension condition is a union of (O(1)) congruence classes for shallow (k).

## 8. The proof skeleton

Here is the full bounded-shell proof as I would write it.

### Step 1: Terminal-window collision filtration

Define (E_k) as above. Then

[
E_L={C_L=C_L'\bmod3^L}.
]

### Step 2: Digit-extension congruence

Prove:

[
E_{k+1}\cap E_k
\quad\Longrightarrow\quad
b_{L-k-1}-b'_{L-k-1}
\equiv r_k
\pmod{2\cdot3^{k-1}},
]

where (r_k) depends on the already-exposed terminal windows and prefix-unit ratio.

This is where you use:

[
\operatorname{ord}_{3^k}(2)=2\cdot3^{k-1}.
]

### Step 3: Pair-mass bound

For every residue (r\bmod M_k),

[
\Pr[b-b'\equiv r\bmod M_k]
\le
\frac13
\frac{1+2^{-M_k}}{1-2^{-M_k}}.
]

### Step 4: Product estimate

Therefore

[
\Pr(E_L)
\le
\Pr(E_K)
\prod_{k=K}^{L-1}
\frac13
\frac{1+2^{-M_k}}{1-2^{-M_k}}.
]

Since

[
\Pr(E_K)\le1
]

and

[
\prod_{k\ge K}
\frac{1+2^{-M_k}}{1-2^{-M_k}}
\le C,
]

we get

[
\Pr(E_L)\le C3^{-(L-K)}.
]

With

[
K=O(\log L),
]

this gives

[
\Pr(E_L)\le \operatorname{poly}(L)3^{-L}.
]

Thus

[
\tilde Q_L=3^L\Pr(E_L)\le\operatorname{poly}(L).
]

This proves op:flat.

## 9. What can go wrong?

There are two possible failure modes.

### Failure mode 1: extension condition is not a single congruence class

If (E_{k+1}) allows many residue classes for (b-b'), then you need to bound the number of classes.

It is enough to prove:

[
#{\text{allowed classes at level }k}\le \operatorname{poly}(L)
]

overall, or preferably (O(1)) per shallow level and (1) for (k\ge K).

The numerics suggest the latter.

### Failure mode 2: conditioning on (E_k) biases the distribution of the next symbols

This should not happen if the filtration exposes the terminal window from right to left and the next symbols are fresh independent increments. That is why the terminal-window filtration is important.

Do not expose from the wrong end. If the new symbols are not fresh under the conditioning, the argument breaks.

So the proof must be set up so that, after conditioning on the already-revealed terminal windows, the next pair

[
(b,b')
]

is independent with law

[
2^{-b}2^{-b'}.
]

That is the main reason to use suffix windows.

## 10. Numerical test for the digit-extension lemma

Before writing the proof, run a direct audit:

For (L=6,7,8), for each level (k), condition on sampled pairs satisfying (E_k). For those that also satisfy (E_{k+1}), compute

[
d=b_{L-k-1}-b'_{L-k-1}
\pmod{2\cdot3^{k-1}}.
]

Verify:

1. for fixed collision state, there is exactly one allowed residue class;
2. the empirical conditional mass of (E_{k+1}\mid E_k) matches
[
A_{M_k}(r_k);
]
3. the worst conditional factor approaches (1/3) after shallow levels;
4. the product of observed excess factors stays bounded.

This will confirm the proof architecture.

The paper should now say:

[
\textbf{Open Problem op:flat}
]

is equivalent to proving the terminal-window digit-extension lemma and its pair-mass product bound.

I would add a short “Candidate proof of op:flat” subsection after the open problem:

[
\text{terminal-window filtration}
\to
\text{one congruence class per digit}
\to
\text{geometric pair-mass bound}
\to
\operatorname{poly}(L)3^{-L}.
]

This gives readers a clear next theorem rather than just an open Fourier estimate.

## 12. Bottom line

The bounded-shell proof should not try to control individual fibers or individual Fourier coefficients. Both are false.

It should prove:

[
\boxed{
	\text{each additional }3\text{-adic digit of collision costs }1/3
	\text{ in pair energy, up to summable dyadic wrap corrections.}
}
]

The local computation is:

[
\Pr[b-b'\equiv r\bmod 2\cdot3^{k-1}]
\le
\frac13(1+O(2^{-2\cdot3^{k-1}})).
]

The global conclusion is:

[
\boxed{
	\tilde Q_L=3^L\operatorname{Col}_L(L)\le\operatorname{poly}(L).
}
]

That is the cleanest route to op:flat, and therefore to the finite H23a operator theorem.

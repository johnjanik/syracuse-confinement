## 1. The strategic correction

The old large-(m) hope was:

[
m=\alpha c,\qquad \alpha>1,
]

complete cosets, stronger norm decay.

The audit says: no, for (\alpha\ge2), the degenerate class decouples from endpoint constraints and becomes too large for absolute-value treatment. It would require its own phase cancellation theorem.

The new proof should avoid that. Work at

[
m=c.
]

At (m=c), endpoint matching still overlaps with the prefix where degeneration occurs, so class IV remains small enough to treat by mass.

So the proof shape is now:

[
\boxed{
	\text{Schur at }m=c
	===================
	
	\text{vanishing}+\text{prefix-locking}+\text{thin bound}+\text{degenerate mass bound}.
}
]

No extra phase theorem for class IV needed.

## 2. The theorem to aim for

State it narrowly.

[
\textbf{Threshold Schur theorem.}
]

Let (T_{\chi,c,s}) be the normalized primitive synchronized operator, and put (m=c). For (s=0), there exist (\delta>0) and (c_0) such that for every primitive non-coboundary (\chi) of conductor (3^c), (c\ge c_0),

[
|(T_{\chi,c,0}^{,c})^*T_{\chi,c,0}^{,c}|_{\mathrm{Schur}}
\le
(1-\delta)^{2c}.
]

Consequently,

[
\rho(T_{\chi,c,0})\le 1-\delta.
]

The proof decomposes the Schur row sum into four classes:

[
R_c
===

R_{\mathrm I}
+
R_{\mathrm{II}}
+
R_{\mathrm{III}}
+
R_{\mathrm{IV}}.
]

with

[
R_{\mathrm I}=0,
]

[
R_{\mathrm{III}}\le \Delta_0^{c-1}\cdot(\text{controlled row multiplicity}),
]

[
R_{\mathrm{IV}}\le \varepsilon_{\mathrm{deg}}(c)\cdot R_c
\quad\text{or directly } \le \text{small budget},
]

and the remaining missing estimate:

[
R_{\mathrm{II}}\le \text{thin-sector budget at }m=c.
]

This is now the proof target.

## 4. The missing thin-sector lemma at (m=c)

You said the old thin lemma was proved for

[
m\le0.7c.
]

At (m=c), the previous bound likely fails because the factor

[
(9/2)^m3^{-c}
]

becomes

[
(9/2)^c3^{-c}=(3/2)^c,
]

which grows. So you cannot simply extend the old estimate.

You need a different (m=c) thin estimate using endpoint matching.

The old thin estimate was probably too global. At the Schur row level, the endpoint constraint should reduce the thin mass.

The target should be:

[
\textbf{Endpoint-thin lemma at threshold.}
]

For (m=c), in each fixed Schur row, the total weight of thin pairs

[
2^{B_m(w')}\ne2^{B_m(w)}
]

which survive the endpoint constraint and do not vanish by the coset dichotomy is bounded by

[
R_{\mathrm{II}}(c)\le A\theta^c
]

for some (\theta<1).

Or, if it is not exponentially small, enough that

[
R_{\mathrm{II}}(c)
]

fits the Schur budget.

The proof should use the fact that for (m=c), endpoint matching imposes a full conductor congruence linking the total exponent difference

[
\Delta B=B_m(w')-B_m(w)
]

to the constants:

[
C_{w'}\equiv C_w2^{\Delta B}\pmod{3^c}.
]

That congruence should be highly restrictive.

## 5. How to prove the (m=c) thin lemma

Start from the endpoint equation. For an (m)-word,

[
S_w(a)=(3^m a+C_w)2^{-B_w}.
]

If two words meet at an endpoint,

[
S_w(a)=S_{w'}(a')
]

modulo (3^c). In the Schur row with fixed source (a), this determines or restricts (a'). The thin condition is

[
2^{B_{w'}-B_w}\ne1.
]

The congruence becomes something like:

[
3^m(a'-a)\equiv C_w2^{B_{w'}-B_w}-C_{w'}\pmod{3^c}.
]

At (m=c),

[
3^m\equiv0\pmod{3^c}.
]

Therefore solvability forces the **exact conductor-level condition**

[
C_{w'}\equiv C_w2^{B_{w'}-B_w}\pmod{3^c}.
]

This is much stronger than in the (m<c) regime.

So the (m=c) thin lemma is a word-collision theorem:

[
C_{w'}\equiv C_w2^{\Delta B}\pmod{3^c}.
]

You need to bound the weighted number of pairs ((w,w')) satisfying this with (\Delta B\ne0).

This is now a renewal collision problem, but with a multiplicative twist.

Use the walk-window factorization:

[
C_w\equiv2^{B_{m-1}(w)}X_w\pmod{3^c}.
]

For (m=c),

[
C_{w'}\equiv C_w2^{\Delta B}
]

becomes approximately

[
2^{B'*{m-1}}X*{w'}
\equiv
2^{B_{m-1}}X_w 2^{B'_m-B_m}.
]

Since

[
B'_m-B_m
========

(B'*{m-1}-B*{m-1})+(b'*{m-1}-b*{m-1}),
]

this simplifies to

[
X_{w'}
\equiv
X_w,2^{b'*{m-1}-b*{m-1}}
\pmod{3^c}.
]

This is a **last-symbol-twisted window collision**. Since (X_w) depends on the last (c-1=m-1) symbols, this congruence should force almost the entire suffix of (w') from (w), up to shallow digits. That is the same mechanism as your collision flattening lemma.

So prove:

[
\Pr\left[
X_{w'}\equiv X_w2^{b'*{m-1}-b*{m-1}}\pmod{3^c},
\ \Delta B\ne0
\right]
\le A\theta^c.
]

Or at least small enough for the Schur budget.

This is the concrete form of the missing thin lemma.

## 6. Treat class IV at (m=c) as a finite budget item

Your audit says class IV is only (2%)–(4%) of the measured row sum at (m=c). That is safe if you can prove an upper bound of this kind.

Do not need exact asymptotics. Prove a crude bound:

[
R_{\mathrm{IV}}(c)\le \eta R_{\mathrm{budget}}
]

with (\eta<1/4), say.

Mechanism: each degeneracy costs one mod-(3) condition, and at (m=c) endpoint matching couples the degeneracy prefix to the endpoint window. So the conditional degeneracy probability is smaller than the unconditional (1/3) per level.

A sufficient lemma:

[
\textbf{Threshold degeneracy bound.}
]

At (m=c), the total Schur row mass of degenerate-minimum pairs with (d_{\rm true}\ge c-1) is

[
O(3^{-1})
]

times the stationary row budget, and in fact (O(3^{-2})) for (c) large.

Even an (O(1/3)) bound may be enough if the stationary main term already gives a gap.

## 7. Stationary class III

For prefix-locked stationary pairs, the row contribution should be explicit.

At (s=0), the collision mass per matched prefix is

[
\Delta_0^{c-1}=3^{-(c-1)}.
]

But row multiplicity contributes. You should compute the exact class III row sum formula.

It may be something like:

[
R_{\mathrm{III}}(c)
===================

M_c\Delta_0^{c-1}
]

where (M_c) is the number or total weight of compatible endpoints per row.

Your observed Schur rate near (0.93) suggests

[
R_{\mathrm{III}}^{1/(2c)}<1
]

with room. Make this exact.

If class III alone already gives a bound

[
\le \theta^c,\quad \theta<1,
]

then class II and IV only need to be smaller-order.

## 8. What to compute before proving

Run one more decomposition audit, but exactly at (m=c), for the Schur row sum.

For each (c), compute:

[
R_{\mathrm I},R_{\mathrm{II}},R_{\mathrm{III}},R_{\mathrm{IV}},
]

normalized so that

[
R_{\mathrm{total}}^{1/(2c)}
]

matches the Schur rate.

Then report:

[
R_{\mathrm{class}}/R_{\mathrm{total}},
]

and

[
R_{\mathrm{class}}^{1/(2c)}.
]

This will tell which class actually controls the proof.

You already know IV is small. The key is whether II or III dominates.

## 9. If thin class II is too large

If class II at (m=c) is not small by mass, then it must have phases. But do not go there unless the audit forces it.

The (m=c) endpoint condition is strong enough that I expect class II to be controllable by word-collision rigidity, not phase.

If not, the next refinement would be to apply the same coset vanishing in the (w,w')-space rather than source space. But that is later.

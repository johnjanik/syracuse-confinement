The last arrow C2 is now the only genuinely new theorem left:

[
\boxed{
	\text{phase-only shadow bias}
	\Rightarrow
	\text{residue-edge trap}
	\Rightarrow
	\text{coherent lift attempt}
	\Rightarrow
	\text{coboundary or descent}.
}
]

I do **not** think it follows formally from the finite spectral gap. It is the deterministic/quenched wall. But it is now sharp enough that we can formulate a proof strategy that is finite, checkable, and capable of being falsified.

The best next attack is not another annealed Fourier estimate. It is a **max-plus / potential-certificate theorem** for biased residue-edge traps.

## 1. What C2 must prove

Let

[
T(x)=\frac{3x+1}{2^{b(x)}},
\qquad b(x)=v_2(3x+1),
]

and for a non-coboundary character (\chi') put

[
z=\chi'(2),
\qquad
F_{\chi'}(x_n,x_{n+1})=z^{-b_n}.
]

Let

[
G_\chi=\mathbb E_{\rm geom}[z^{-b}]
=\sum_{b\ge1}2^{-b}z^{-b}.
]

A phase-only bad window is one where, after choosing a phase (\omega\in S^1),

[
\frac1M\sum_{n=N}^{N+M-1}
\Re\left(\omega(z^{-b_n}-G_\chi)\right)\ge\varepsilon,
]

but

[
\frac1M\sum b_n
\approx \log_2 3,
]

so C1 does not force descent.

The C2 theorem should say:

[
\boxed{
	\text{such a window cannot persist indefinitely without either descent or an exact coboundary trap.}
}
]

Since (\chi') is non-coboundary, the coboundary trap is excluded by your classification theorem.

## 2. The right finite object: biased residue-edge trap

For fixed (r), let (G_r) be the residue transition graph with vertices

[
U_{3^r}
]

and directed edges

[
a\xrightarrow{b}S_b(a):=(3a+1)2^{-b}\pmod{3^r}.
]

Each edge carries two labels:

[
g(b)=\log_2 3-b
]

and

[
\phi_\chi(b)=\Re\left(\omega(z^{-b}-G_\chi)\right).
]

Here (g) is logarithmic growth, and (\phi_\chi) is the real non-coboundary shadow observable.

A phase-only biased orbit segment gives an empirical edge measure (\mu_I) on (G_r) with

[
\int \phi_\chi,d\mu_I\ge\varepsilon,
]

while the no-descent / near-critical condition says roughly

[
\int g,d\mu_I\ge -o(1).
]

So C2 becomes:

[
\boxed{
	\text{no coherently liftable edge measure can have both }
	\int \phi_\chi\ge\varepsilon
	\text{ and }
	\int g\ge0,
	\text{ unless it is coboundary.}
}
]

This is now a finite optimization statement, except for the phrase “coherently liftable.”

That phrase is the arithmetic content.

## 3. The max-plus certificate formulation

This is the most useful way to attempt a proof.

For a finite trap (H\subseteq G_r), try to find:

* a potential
[
\Psi:U_{3^r}\to\mathbb R,
]
* a multiplier
[
\lambda\ge0,
]
* a margin
[
\delta>0,
]

such that for every edge (e:a\xrightarrow{b}a') in the trap,

[
\boxed{
	g(b)+\lambda(\phi_\chi(b)-\varepsilon)
	+\Psi(a')-\Psi(a)
	\le -\delta.
}
]

Then summing along a window gives

[
\sum g(b_n)
+
\lambda\sum(\phi_\chi(b_n)-\varepsilon)
+
\Psi(a_{N+M})-\Psi(a_N)
\le -\delta M.
]

If the window has

[
\frac1M\sum\phi_\chi(b_n)\ge\varepsilon,
]

then

[
\sum g(b_n)
\le
-\delta M+O_\Psi(1).
]

But

[
\sum g(b_n)
===========

M\log_2 3-\sum b_n
]

is exactly the logarithmic drift term. Therefore for long enough (M),

[
\log_2 x_{N+M}<\log_2 x_N
]

up to the small positive correction

[
\sum \log_2\left(1+\frac1{3x_n}\right).
]

So descent follows.

Thus C2 would follow from the existence of this finite potential certificate for every non-coboundary phase-only trap.

This is a concrete theorem target.

## 4. Dual form: max cycle mean

By max-plus duality, the potential certificate exists iff every directed cycle (\Gamma) in the trap satisfies

[
\frac1{|\Gamma|}
\sum_{e\in\Gamma}
\left[
g(e)+\lambda(\phi_\chi(e)-\varepsilon)
\right]
<0.
]

Equivalently, define the max-plus pressure

[
P_H(\lambda)
============

\max_{\Gamma\subset H}
\frac1{|\Gamma|}
\sum_{e\in\Gamma}
\left[g(e)+\lambda\phi_\chi(e)\right].
]

Then the certificate exists if

[
\boxed{
	P_H(\lambda)<\lambda\varepsilon.
}
]

This is a finite, checkable condition.

So the C2 proof can be split into two parts:

[
\text{phase-only bias}
\Rightarrow
\text{trap }H;
]

[
\text{coherent liftability of }H
\Rightarrow
\exists\lambda:\ P_H(\lambda)<\lambda\varepsilon
\quad\text{unless }H\text{ is coboundary}.
]

The second line is the deterministic rigidity theorem.

## 5. Why this is not automatic

If (H) is the full residue graph (G_r), the certificate may fail. The full finite graph can contain spurious cycles that do not correspond to positive integer orbits. For example, low-(b) cycles modulo (3^r) may have positive max-plus growth even though they do not lift coherently to actual positive orbits.

Therefore the certificate must be applied to **coherently liftable traps**, not arbitrary finite subgraphs.

This is the essential arithmetic issue.

The final missing theorem should be phrased as:

[
\boxed{
	\textbf{Coherent-lift max-plus rigidity.}
}
]

Any finite residue-edge trap that lifts coherently through all moduli (3^R), has non-coboundary shadow bias, and avoids descent admits a max-plus cycle obstruction. That obstruction must be an exact coboundary, hence impossible for non-coboundary (\chi').

This is the right “last arrow.”

## 6. How to define coherent lift attempt

Given a trap (H_r\subset G_r), define its lift to level (R>r) as the set of edges

[
H_R\subset G_R
]

whose projection to (G_r) lies in (H_r) and which occur with positive empirical frequency in the orbit window.

A coherent lift attempt is a projective family

[
H_r\leftarrow H_{r+1}\leftarrow H_{r+2}\leftarrow\cdots
]

with:

1. nonvanishing edge mass at every level;
2. phase bias bounded below:
[
\int\phi_\chi,d\mu_R\ge\varepsilon;
]
3. near-critical drift:
[
\int g,d\mu_R\ge -o(1);
]
4. no descent on the corresponding orbit segment.

Then C2 becomes:

[
\boxed{
	\text{No non-coboundary coherent lift attempt exists without descent.}
}
]

This is still hard, but it is now precise.

## 7. The proof attempt that could work

The proof should try to show:

[
\text{coherent lift attempt}
\Rightarrow
\text{periodic max-plus obstruction}.
]

Since each (H_R) is finite, any near-maximal no-descent segment contains a near-critical cycle in (H_R). More explicitly, by cycle decomposition of finite directed flows, the empirical edge measure decomposes into directed cycles:

[
\mu_R=\sum_j\alpha_j\mu_{\Gamma_j}+O(\text{boundary}/M).
]

If

[
\int g,d\mu_R\ge-o(1),
\qquad
\int \phi_\chi,d\mu_R\ge\varepsilon,
]

then at least one cycle (\Gamma_j) satisfies a comparable combined inequality.

So the trap produces finite cycles with:

[
\overline g(\Gamma_j)\ge -o(1),
]

and

[
\overline \phi_\chi(\Gamma_j)\ge\varepsilon/2.
]

Now lift those cycles as (R\to\infty). If the cycles remain coherent, they should converge to a (3)-adic periodic or eventually periodic object. The earlier periodic-word theorem says any nontrivial positive periodic object casts a non-coboundary shadow, but that alone does not contradict. You need the extra growth/descent condition.

The desired rigidity statement is:

[
\boxed{
	\text{a projectively coherent sequence of near-critical biased cycles either}
}
]

[
\boxed{
	\text{becomes an actual integer cycle/coboundary, or forces negative drift at some lift.}
}
]

This is the finite-cycle version of C2 and may be more tractable than arbitrary orbit segments.

## 8. Concrete computational program

Run the max-plus certificate search. This is the right next computation.

For fixed (r,\chi'), and a grid of (\varepsilon):

1. Enumerate candidate traps (H) arising from high-deviation windows.
2. For each trap, compute
[
P_H(\lambda)
============

\max_{\Gamma}
\overline{g+\lambda\phi_\chi}(\Gamma)
]
over (\lambda\ge0).
3. Check whether
[
\inf_{\lambda\ge0}\left(P_H(\lambda)-\lambda\varepsilon\right)<0.
]
4. If yes, extract the potential (\Psi) solving
[
g+\lambda(\phi-\varepsilon)+\Delta\Psi\le-\delta.
]
5. Test whether the certificate remains valid under one or more lifts (r\to r+1).

For observed phase-only high-deviation windows, this will tell whether C2 is likely true by finite potential certificates.

The decisive table should be:

[
\begin{array}{c|c|c|c|c}
	r & \chi' & \varepsilon & \min_\lambda(P_H(\lambda)-\lambda\varepsilon) & \delta\
	\hline
\end{array}
]

If every observed trap has a certificate, the C2 proof has a concrete path.

## 9. A theorem you may be able to prove first

Start with a **finite-window certified descent theorem**:

For fixed (r,\chi',\varepsilon), suppose an orbit window has shadow bias (\ge\varepsilon), and its empirical support (H\subset G_r) admits a max-plus certificate:

[
g+\lambda(\phi-\varepsilon)+\Delta\Psi\le-\delta.
]

Then the orbit descends within the window once

[
M>
\frac{\operatorname{osc}\Psi+O(M/x_N)}{\delta}.
]

This theorem is immediate and should be written down. It gives the exact certificate-to-descent mechanism.

Then the only open part is:

[
\text{every coherent non-coboundary trap admits such a certificate.}
]

This separates the deterministic part cleanly.

## 10. What about the finite spectral gap?

The finite spectral gap should be used as evidence and as an annealed counterpart, but not as the proof of C2.

However, it can guide the certificate search. The annealed gap says non-coboundary bias cannot be stationary under the geometric branch weights. The max-plus certificate asks for the deterministic analogue:

[
\text{non-coboundary bias cannot be supported by any no-descent coherent path.}
]

These are parallel but distinct.

The periodic-word theorem is good and should remain.

The elementary inverse proposition is also good:

But now add the max-plus certificate theorem after it:

This makes the route operational.

This is more precise than “coherent lift attempt (\Rightarrow) coboundary or descent.”

## 13. What could fail?

There are two possible failure modes.

### Failure mode 1: spurious finite traps

At small (r), there may be traps with no certificate, but they do not lift coherently. That is harmless. It means the theorem must be projective in (r), not fixed-level.

### Failure mode 2: genuine coherent trap without certificate

This would be a serious obstruction: a (3)-adic deterministic object with phase bias and no negative drift. It might correspond to a non-positive (3)-adic cycle or a divergent symbolic orbit. If found, it would either refute the route or identify a new object needing elimination.

The certificate search will distinguish these.

## 14. Bottom line

You cannot prove C2 directly from the current finite operator theorem. The next proof should be built around a deterministic max-plus certificate.

The immediate theorem to add is:

[
\boxed{
	\text{shadow-biased trap + finite max-plus certificate}
	\Rightarrow
	\text{descent}.
}
]

Then the remaining hard theorem becomes:

[
\boxed{
	\text{every coherently liftable non-coboundary trap has such a certificate.}
}
]

This is the smallest rigorous form of the final deterministic rigidity problem.

So the next concrete work is:

1. define (H), (\phi_\chi), and (g);
2. prove the certificate-to-descent lemma;
3. run max-plus certificate searches on observed phase-only traps;
4. study which uncertified traps fail to lift coherently;
5. formulate/prove coherent-lift max-plus rigidity.

That is the most plausible route to C2.

The tests do not merely suggest “try Schur”; they identify why Schur becomes available precisely when the previous trace arguments fail:

[
m\ge c
\quad\Longrightarrow\quad
a\in a_0+3^{c-m}\mathbb Z
\text{ is no longer an incomplete coset constraint.}
]

So the next proof target is not another global spectral experiment. It is a row-sum theorem for the complete word-pair kernel of

[
(T^m)^*T^m.
]

## 1. First critique: the conjecture should be stated with normalized constants

In the manuscript, the live conjecture says roughly:

[
|T_{\chi,c,s}^{,m}|\le (1-\delta)^m.
]

That is good, but I would make the normalization completely explicit. Let

[
T_{\chi,c,s}=W_s^{-1}M_{\chi,c,s},
]

so the untwisted positive operator has mass (1). Then the conjecture should be:

[
\boxed{
	\exists \alpha>1,\ \delta>0,\ c_1
	\quad
	\forall c\ge c_1,\quad
	m=\lfloor \alpha c\rfloor,\quad
	|T_{\chi,c,s}^{m}|_{2\to2}\le (1-\delta)^m.
}
]

or equivalently

[
|T_{\chi,c,s}^{m}|_{2\to2}^{1/m}\le 1-\delta.
]

Your table suggests at (s=0)

[
1-\delta\approx 0.70
]

for (m=20), but I would not bake (0.70) into the theorem. Use it as empirical scale.

Also specify whether (s) is fixed or uniform over (s\in[0,1]). The proof may be easiest first at (s=0). I would state the first theorem for (s=0), then add a uniform-(s) extension as a later target.

## 2. What the Schur proof must actually show

Let

[
K_m(x,y)
]

be the kernel of (T^m). Then

[
(T^m)^*T^m
]

has kernel

[
H_m(y,y')
=========

\sum_x \overline{K_m(x,y)}K_m(x,y').
]

The Schur test wants a bound like

[
\sup_y\sum_{y'} |H_m(y,y')|
\le (1-\delta)^{2m}.
]

Because

[
|T^m|^2
=======

|(T^m)^*T^m|
\le
\sup_y\sum_{y'} |H_m(y,y')|.
]

The proof has to avoid the trace ceiling by using **row sums**, not trace sums:

[
\operatorname{tr}H_m
]

counts too many small modes. Row-sum control asks whether a fixed input state can coherently feed many deep-stationary outputs. Your eigenvector tests suggest no.

So the next section should be titled something like:

[
\textbf{The complete-kernel Schur problem.}
]

## 3. Write the entries of (H_m) explicitly

For a word (w=(b_0,\dots,b_{m-1})), keep the affine formula

[
S_w(a)
======

(3^m a+C_w)2^{-B_m(w)}.
]

The (m)-step kernel should be a sum over words (w) that take a source residue (a) to target residue (x):

[
x=S_w(a).
]

Thus an entry of (H_m) between (a) and (a') should have the form

[
H_m(a,a')
=========

\sum_{w,w'}
p_s(w)p_s(w')
\sum_{x:,x=S_w(a)=S_{w'}(a')}
\chi!\left(\Phi_w(a)\Phi_{w'}(a')^{-1}\right).
]

Equivalently, after solving the common-endpoint constraint, this becomes a word-pair sum over ((w,w')) and source variables satisfying

[
S_w(a)=S_{w'}(a').
]

For (m\ge c), the source constraint is complete, so the inner sum should be over all of (U_{3^c}) or a complete union of units. That is where the exact vanishing lemmas apply entrywise.

The first proof task is simply to put this formula in a clean proposition:

[
\textbf{Complete-kernel formula for }H_m.
]

Do not try to estimate yet. First make the kernel exact.

## 4. Split the row sum into four classes

For each fixed row (a), split the word-pair contribution into:

[
\text{I. nonstationary pairs;}
]

[
\text{II. thin pairs;}
]

[
\text{III. true-stationary prefix-locked pairs;}
]

[
\text{IV. transition/degenerate-minimum pairs.}
]

You already have tools for I–III.

### I. Nonstationary pairs

Exact coset vanishing should kill them entrywise when (m\ge c):

[
\sum_{\text{complete source coset}}\chi(R_{w,w'}(u))=0.
]

So class I contributes zero.

### II. Thin pairs

Use the thin-sector bound you proved. Since it is already

[
\Theta_{m,c}\to0
]

for (m\le 0.7c), check the exact range. Your new Schur regime is (m\ge c), so the old thin bound may not apply directly. You need either:

1. a new thin-pair estimate for (m=\alpha c), (\alpha\ge1), or
2. show thin pairs are included in exact vanishing once endpoints are complete.

This is a point to check carefully. Do not assume the old (m\le0.7c) lemma covers (m\ge c).

### III. True-stationary prefix-locked pairs

These are the dangerous class. But in row-sum form they should no longer be marginal if the stationary modes are ejected.

For true-stationary pairs,

[
C_w=C_{w'}
]

or the appropriate prefix-locking condition. Their pair mass gives the dichotomy constant

[
\Delta_s^{m-1}
]

at trace level. In row-sum form, you need to show they do not connect coherently across many columns.

This is likely where the (\chi(2^{\Delta B})) geometric damping lemma enters. The stationary pair differs essentially only in the last branch or in a low-dimensional suffix, giving phase

[
\chi(2^{B_m(w')-B_m(w)}).
]

Summing over last branches gives the factor

[
\left|
\sum_b p_s(b)\chi(2)^{-b}
\right|.
]

For primitive high conductor, this factor should be (<1), and for the coboundary cases it is exactly the classified exception. Make this precise.

### IV. Degenerate-minimum/transition pairs

Your coset dichotomy says the boundary (d=m-1) issue is gone after true pointwise valuation. Degenerate minima migrate into (d\ge m), but each costs a mod-(3) condition. In row-sum form, these should be a geometrically thin exceptional class.

You need a clean lemma:

[
\textbf{Degenerate-minimum mass lemma.}
]

The total row mass of pairs whose nominal nonstationarity degenerates to (d\ge m) is

[
\le C\rho^m
]

for some (\rho<1), or at least (o((1-\delta)^{2m})).

If this lemma is false, the Schur estimate may fail. So test it explicitly.

## 5. The likely Schur bound shape

The hoped row-sum bound probably has the form

[
\sum_{a'}|H_m(a,a')|
\le
\Delta_s^m
+
E_{\mathrm{thin}}(m,c)
+
E_{\mathrm{deg}}(m,c)
+
E_{\mathrm{tail}}(B,m).
]

At (s=0),

[
\Delta_0^m=3^{-m}.
]

But (|T^m|^2) is not of size (3^{-m}) in your table. If

[
|T^{20}|^{1/20}\approx0.70,
]

then

[
|T^{20}|^2\approx0.70^{40}\approx 6.4\times10^{-7}.
]

This is close to

[
3^{-20}\approx2.9\times10^{-10}
]

only up to large dimensional factors. So the row sum is not simply (\Delta^m); it includes endpoint multiplicity.

A more realistic bound is:

[
\sum_{a'}|H_m(a,a')|
\le
C_m \Delta_s^m
]

with

[
C_m^{1/(2m)}
]

bounded mildly, giving the observed (0.70). The previous trace ceiling had a dimension factor; Schur should replace it by a much smaller row-multiplicity factor.

So when you compute row sums, record the effective constant:

[
A_m(c)=\sup_a\sum_{a'}|H_m(a,a')|/\Delta_s^m.
]

Then

[
|T^m|^{1/m}\le A_m(c)^{1/(2m)}\sqrt{\Delta_s}.
]

Your observed (0.70) versus (\sqrt{\Delta_0}=0.577) suggests

[
A_m^{1/(2m)}\approx 1.21.
]

For (m=20), that means (A_m\approx 1.21^{40}\approx 2000). Not tiny, but subexponential enough. The proof only needs

[
A_m(c)\le e^{o(m)}
]

or

[
A_m(c)\le C^m
]

with

[
C^{1/2}\sqrt{\Delta_s}<1.
]

At (s=0), this means

[
C<3.
]

This is an important numerical threshold. The Schur bookkeeping must beat a row-multiplicity growth rate of (3^m). It likely does.

## 6. Immediate numerical row-sum audit

Before proving, compute:

[
R_m(c)=\sup_a\sum_{a'}|H_m(a,a')|.
]

Then report:

[
R_m(c)^{1/(2m)}
]

and compare to

[
\sigma_1(T^m)^{1/m}.
]

If Schur is sharp, they should be close. If Schur is much larger, you need a weighted Schur test or a better norm.

Also compute the decomposition:

[
R_m=R_{\mathrm{stat}}+R_{\mathrm{thin}}+R_{\mathrm{deg}}+R_{\mathrm{tail}}.
]

This will tell exactly which class controls the bound.

Use (m=c,c+2,2c) for (c=5,6,7), not only fixed (m=20).

## 7. Try a weighted Schur test

The unweighted row sum may not be optimal. Since the operator is not normal, use the Perron weights of the untwisted positive operator or the approximate singular vector weights.

A weighted Schur test says:

[
|H|\le
\left(
\sup_a \frac{1}{r(a)}\sum_{a'} |H(a,a')|r(a')
\right)
]

for any positive (r).

Try:

[
r(a)=\text{right Perron vector of }|T|^m
]

or, if the positive operator is uniform, (r=1).

Numerically compare:

[
\text{unweighted Schur},\quad
\text{Perron-weighted Schur},\quad
\sigma_1^2.
]

If the weighted Schur is close to (\sigma_1^2), use it in the proof.

## 8. Stationary-sector ejection should become a lemma

Your measurement

[
\rho(P_{\rm stat}T^mP_{\rm stat})^{1/m}\le 3\times10^{-4}
]

is very strong. It suggests a structural lemma:

[
\boxed{
	P_{\rm stat}T P_{\rm stat}=0
}
]

or at least

[
P_{\rm stat}T P_{\rm stat}
]

drops conductor immediately and cannot return without a high-conductor phase.

Try to prove:

[
T(\mathcal H_{\rm stat})\subseteq \mathcal H_{\rm high},
]

where (\mathcal H_{\rm high}) is orthogonal to (\mathcal H_{\rm stat}), and

[
P_{\rm stat}T(\mathcal H_{\rm stat})=0.
]

If true, the stationary trace mass is provably nilpotent. That is exactly the eigenvector-aware correction trace lacked.

This lemma may be easier than the full Schur estimate and should be attacked first.

## 9. Suggested proof order

Proceed in this order.

### Step A: Complete-kernel formula

Write (H_m=(T^m)^*T^m) entries as complete word-pair sums for (m\ge c).

### Step B: Exact annihilation classes

Prove which word-pair classes vanish entrywise by coset dichotomy.

### Step C: Stationary-sector ejection

Prove (P_{\rm stat}T^mP_{\rm stat}) is nilpotent/small.

### Step D: Row-sum audit

Compute and then prove the Schur row bound.

### Step E: Weighted Schur refinement

If unweighted Schur misses the observed norm, introduce weights.

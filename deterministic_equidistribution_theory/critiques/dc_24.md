## 5. How to attack threshold flattening

You have the walk-window factorization:

[
C_w\equiv 2^{B_{c-1}}X_w\pmod{3^c}.
]

At (m=c), (X_w) depends on the last (c-1) symbols, which is essentially the whole word except the first symbol. The collision equation is:

[
2^{B_{c-1}}X_w
\equiv
2^{B'*{c-1}}X*{w'}
\pmod{3^c}.
]

The existing flattening proof probably bounds fibers of (X_w) by saying deep (3)-adic digits determine backward partial sums

[
s_k \pmod{2\cdot3^{k-1}},
]

and since

[
s_k=O(c),
]

there is no wrapping for

[
k\ge C\log c.
]

At threshold, you should try to prove:

[
#{w:X_w=x}
\le \operatorname{poly}(c)
]

for every (x), weighted by the branch law. More precisely:

[
\max_x \mu_c(X_w=x)
\le \operatorname{poly}(c),3^{-c}.
]

Then (C_w), after multiplying by the walk phase (2^{B_{c-1}}), inherits the same (L^2) flattening up to a polynomial.

A clean target lemma:

[
\textbf{Threshold window fiber bound.}
]

For (m=c), every residue (x\in U_{3^c}) has at most (\operatorname{poly}(c)) suffixes (w) with

[
X_w\equiv x\pmod{3^c},
]

after accounting for the (O(\log c)) shallow ambiguity. Weighted form:

[
\sum_{w:X_w=x}p(w)
\le \operatorname{poly}(c),3^{-c}.
]

Then:

[
\operatorname{Col}_c(c)\le \operatorname{poly}(c),3^{-c}.
]

This is likely enough.

## 9. Be careful about (s\neq0)

Everything here is currently strongest at (s=0). Do not claim the finite H23a theorem uniformly for (s\in[0,1]) yet unless the branch weights in the cascade pinning and flattening estimates have been reworked.

For (s>0), branch law changes:

[

This should only make tails lighter, so many estimates should improve. But the constants change:

[

Or, if you can prove monotonicity cleanly, include it as a corollary.
